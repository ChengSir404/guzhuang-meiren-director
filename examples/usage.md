# 使用示例

这些示例展示如何调用 Skill，以及它应自动补全哪些内容。实际成品会按 `references/prompt-architecture.md` 输出九层导演式完整提示词或精简提示词。

## 1. 极简人物想法

```text
使用 $guzhuang-meiren-director 美化：一位清冷古装女子。
```

预期：默认补全 20–25 岁成年东方古典人物；选择单一身份原型、主时代气质、服装、妆发、主道具、具体动作、环境、镜头和安全约束，不把所有古风元素堆在一起。

## 2. 侠女与骑马

```text
使用 $guzhuang-meiren-director 完善：一位侠女骑马经过山道，英气但不要僵硬。
```

预期：马匹、缰绳、鞍具、人物腿位和运动方向符合物理关系；服装与发髻适合骑行；动作写到身体重心、手部职责、视线与衣摆受风，不使用影楼式静态摆拍。

## 3. 琴棋书画

```text
使用 $guzhuang-meiren-director 写一版宋韵才女弈棋的 ChatGPT 文生图提示词。
```

预期：只把棋局作为主道具，书卷、琴、画不同时堆入；自动匹配宋韵清雅服装、简簪、案几、庭院或书房，并设计落子前的手势、视线和思考神态。

## 4. 花与季节

```text
使用 $guzhuang-meiren-director 完善：一位贵女在花树下，画面明亮，有抓拍感，不要樱花。
```

预期：根据季节选择海棠、梨花、牡丹或梅花中的一种；让花枝、花瓣、人物动作、服装配色与光线形成统一叙事。

## 5. 敦煌灵感安全改写

```text
使用 $guzhuang-meiren-director 把“菩萨装扮、又纯又欲”改成安全、高级的 ChatGPT 文生图提示词。
```

预期：改写为“受敦煌壁画或菩萨造像服饰启发的成年东方女子”；以圣洁端庄为主，用宁静眼神、完整衣着、珠玉、丝绸和优雅体态表现柔美女性魅力，不色情化真实宗教对象。

## 6. 指定精简版

```text
使用 $guzhuang-meiren-director 美化下面的提示词，只给精简版，控制在七段以内：……
```

预期：保留成年身份、安全衣着、核心服装、主道具、关键动作、镜头环境与主要失败约束，删除同义词堆叠。

## 7. 基于参考图

```text
使用 $guzhuang-meiren-director 保持参考图人物的脸和身份，只把服装改成明代端丽风格，并补全发饰、庭院背景与自然动作。
```

预期：参考图身份与当前明确要求优先；只补全未指定部分，不让场景参考改变人物脸，也不把审美默认值覆盖到已明确的特征上。

## 8. 指定身材与衣着轮廓

```text
使用 $guzhuang-meiren-director 完善：一位柔和梨形身材的成年盛唐贵女，胸部是自然丰满的水滴形轮廓，服装完整端庄，不要把身体曲线作为画面焦点。
```

预期：先写肩线、腰胯、整体体态，再将水滴形转成“上部过渡柔和、下部自然丰盈”的衣着轮廓；通过完整不透明的高腰裙、丝料垂坠和披帛自然呈现，避免挤压、深 V、透视、敏感部位特写和极端胸腰比。

## 9. 避免参数清单感

```text
使用 $guzhuang-meiren-director 丰富：盛唐贵女在牡丹花下，不要只是堆服饰名词，要像电影抓拍。
```

预期：先确定“宫宴将散，她收扇时看见迟到之人”的决定性瞬间；脸和眼神为第一锚点，收扇的手为第二锚点，高髻与高腰裙形成第三层轮廓。花影落在衣袖、步摇因停步仍有轻微余摆，环境和饰品共同响应动作；配色只保留主色、辅色和一个点睛色。

## 10. 环境参与动作

```text
使用 $guzhuang-meiren-director 完善：雨后山道上的骑马侠女，英气、真实、有故事感。
```

预期：不只写“竹林、薄雾、电影感”，而写马刚踏进浅水、前蹄溅起泥水，侠女右手勒缰、左手按剑鞘，重心随马停步后移；湿润石面反射冷天光，披风和马鬃保留运动惯性，人物脸由阴天柔光和路面积水反光共同照亮。
