# 请求示例

普通请求默认输出九模块，不需要每次强调模板。

| 请求 | 应有行为 |
|---|---|
| 写一位花海里的古装仙子，真人 | 九模块，补必要设计，不自动加胸型，不把人物画成3D |
| 固定平口胸型，肩部有透明丝绸长袖 | 体积、形状与领口仅在服装模块一次展开；内搭不透明，薄袖实际覆盖肩部 |
| B～C水滴形，柳叶眼，宽台盘腿坐 | 保留具体体积和形状，腿收在台面上；不改圆锥或双腿垂地 |
| 换成狐狸眼，其他都不变，只给替换句 | 只改眼型描述，不加狐狸耳、兽瞳或换脸型 |
| 成熟御姐，二郎腿，脚尖勾鞋，脚部完整 | 神态稳定自然，明确上方脚与鞋的接触；下方脚支撑，脚不出画 |
| 这次全部换，不要又是庭院里托花 | 更换空间结构、动作、表情、服装与光影方向；保留锁定人物要求 |
| 只修皮肤，不要那么锐，保留全身 | 只调整肤质与相关光感，不换脸、不裁半身 |
| 给一段话，未指定的鞋色别写死 | 单段，仅补关键内容，不额外附九模块 |
| 用固定脚链模板，只戴一只脚 | 单侧脚链，保留鞋履、裙长与构图 |
| 精确复原南宋日常女装并附依据 | 核对权威资料，区分实物依据与推断，不把仙侠改良装称复原 |
