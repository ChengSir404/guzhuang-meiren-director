# 使用示例

这些示例展示如何调用 Skill，以及它应自动补全哪些内容。实际输出按请求选择连贯提示词、可选九层导演版、原稿整理或局部替换；九层只作为内部覆盖检查。

## 1. 极简人物想法

```text
使用 $guzhuang-meiren-director 美化：一位清冷古装女子。
```

预期：默认补全 20–25 岁成年东方古典人物；选择单一身份原型、主时代气质、服装、妆发、主道具、具体动作、环境、镜头和安全约束，不把所有古风元素堆在一起。

## 2. 侠女与骑马

```text
使用 $guzhuang-meiren-director 完善：一位侠女骑马经过山道，英气但不要僵硬。
```

预期：马匹、缰绳、鞍具、人物腿位和运动方向符合物理关系；服装与发髻适合骑行；动作写到身体重心、手部职责、视线与衣摆受风，不使用影楼式静态摆拍。

## 3. 琴棋书画

```text
使用 $guzhuang-meiren-director 写一版宋韵才女弈棋的 ChatGPT 文生图提示词。
```

预期：只把棋局作为主道具，书卷、琴、画不同时堆入；自动匹配宋韵清雅服装、简簪、案几、庭院或书房，并设计落子前的手势、视线和思考神态。

## 4. 花与季节

```text
使用 $guzhuang-meiren-director 完善：一位贵女在花树下，画面明亮，有抓拍感，不要樱花。
```

预期：根据季节选择海棠、梨花、牡丹或梅花中的一种；让花枝、花瓣、人物动作、服装配色与光线形成统一叙事。

## 5. 敦煌灵感安全改写

```text
使用 $guzhuang-meiren-director 把“菩萨装扮、又纯又欲”改成安全、高级的 ChatGPT 文生图提示词。
```

预期：改写为“受敦煌壁画或菩萨造像服饰启发的成年东方女子”；以圣洁端庄为主，用宁静眼神、完整衣着、珠玉、丝绸和优雅体态表现柔美女性魅力，不色情化真实宗教对象。

## 6. 指定精简版

```text
使用 $guzhuang-meiren-director 美化下面的提示词，只给精简版，控制在七段以内：……
```

预期：保留成年身份、安全衣着、核心服装、主道具、关键动作、镜头环境与主要失败约束，删除同义词堆叠。

## 7. 基于参考图

```text
使用 $guzhuang-meiren-director 保持参考图人物的脸和身份，只把服装改成明代端丽风格，并补全发饰、庭院背景与自然动作。
```

预期：参考图身份与当前明确要求优先；只补全未指定部分，不让场景参考改变人物脸，也不把审美默认值覆盖到已明确的特征上。

## 8. 指定身材与衣着轮廓

```text
使用 $guzhuang-meiren-director 完善：一位柔和梨形身材的成年盛唐贵女，胸部是自然丰满的水滴形轮廓，服装完整端庄，不要把身体曲线作为画面焦点。
```

预期：先写肩线、腰胯、整体体态，再将水滴形转成“上部过渡柔和、下部自然丰盈”的衣着轮廓；通过完整不透明的高腰裙、丝料垂坠和披帛自然呈现，避免挤压、深 V、透视、敏感部位特写和极端胸腰比。

## 9. 避免参数清单感

```text
使用 $guzhuang-meiren-director 丰富：盛唐贵女在牡丹花下，不要只是堆服饰名词，要像电影抓拍。
```

预期：先确定“宫宴将散，她放低团扇时看见迟到之人”的决定性瞬间；脸和眼神为第一锚点，放扇的手为第二锚点，高髻与高腰裙形成第三层轮廓。花影落在衣袖、步摇因停步仍有轻微余摆，环境和饰品共同响应动作；配色只保留主色、辅色和一个点睛色。

## 10. 环境参与动作

```text
使用 $guzhuang-meiren-director 完善：雨后山道上的骑马侠女，英气、真实、有故事感。
```

预期：不只写“竹林、薄雾、电影感”，而写马刚踏进浅水、前蹄溅起泥水，侠女右手勒缰、左手按剑鞘，重心随马停步后移；湿润石面反射冷天光，披风和马鬃保留运动惯性，人物脸由阴天柔光和路面积水反光共同照亮。

## 11. 惊艳美貌与清晰脸部

```text
使用 $guzhuang-meiren-director 改进：人物虽然漂亮但不够惊艳，而且脸有点糊。保留盛唐贵女和牡丹主题，重点提升脸。
```

预期：选择“明艳贵气”单一方向，在默认 9:16 竖版中使用腰上至大腿中部中近景，让人物占画面高度约 85%–92%、脸部约占 18%–22%，避免为了展示高髻、全套长裙和庭院而缩小脸部；用柔和鹅蛋脸、舒展长眉与清亮杏眼形成主对比，以朱红唇或小花钿作为唯一高纯度色彩焦点。近正面轻微转脸，两只眼睛完整可见且同焦；面部使用侧前方柔光和环境补光，花枝、披帛、发丝、斑驳阴影与雾气不得遮挡五官，动态模糊只允许落在花瓣或垂饰上。

## 12. 修复很长但不稳定的提示词

```text
使用 $guzhuang-meiren-director 改进下面这份很长的明代贵女提示词。保留 9:16 竖版、江南庭院、合扇瞬间和清晰脸部，不要重写成更多段落：……
```

预期：保留原稿段落，不新增分区，把重复的主题、五官、镜头、细节强化和负面要求合并到对应原段；将“朱砂红或石榴红”“金簪或玉簪”“整理袖口或扶云肩”等未决选项各自解析为一个确定方案，只保留 5–8 个高价值视觉锚点。9:16 竖版使用紧凑中近景和有限方向留白，不能为了展示庭院、高髻与长裙而缩小人物脸；“听见身后有人却目光自然望向前方”等矛盾应改成一致的来源、眼神、头肩和重心响应。

## 13. 多参考图职责分离

```text
使用 $guzhuang-meiren-director：图1保持人物脸和身份，图2只参考明制袄裙，图3只参考庭院光色；生成同一人物在回廊合扇的 9:16 提示词。
```

预期：在成品前用一小段明确图1是身份参考、图2是服装结构参考、图3是环境光色参考，并写明图2和图3的模特脸、姿势与无关饰品不得迁移。若图片之间冲突，按用户当前文字要求与身份参考优先，不笼统写“参考以上图片”。

## 14. 根据失败出图做单变量修复

```text
使用 $guzhuang-meiren-director 看这张生成图：服装和庭院都满意，但脸太小、不够惊艳。只修脸部表现，其他不要变。
```

预期：先检查整幅图，再检查脸部区域；冻结人物身份、明制服装、合扇动作、庭院和主配色，先修景别与人物占比，不改变人物签名、脸型或眼型；仅在仍有可见问题时调整对焦或面光。没有原稿时给完整修复提示词，有原稿时给对应替换段，并说明修复范围。
