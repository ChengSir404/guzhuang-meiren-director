# 导演版成品示例

这些示例展示复杂故事画面的可选九层交付，不是所有任务的固定格式。

## 标杆一：宫宴将散的盛唐贵女

```text
【画面命题】请生成一幅真人写实、东方古典电影感人物画：暮春宫宴将散，一位 24 岁、明确成年的盛唐贵女在牡丹花径边放低团扇；她原本正从容离席，却在听见廊下脚步时停住半步，目光越过镜头左侧，从平静中泄露一瞬迟疑。

【人物辨识度】柔和鹅蛋脸，脸颊有自然丰润感；舒展长眉与清澈含蓄的杏眼形成温柔而清醒的神情，鼻梁自然、唇峰清楚，嘴角左右略有极轻微差异。皮肤白皙通透但保留细小绒毛、唇纹和眼下淡影，拒绝网红模板脸与瓷偶磨皮。

【妆发饰品】乌发梳成轮廓饱满但不过高的唐风高髻，以一支金质花树钗为主焦点，辅以两枚小花梳和一对温润珍珠耳坠；朱红花钿小巧贴合眉眼。贵女突然停步，花树钗垂饰与耳坠仍保留轻微余摆，鬓边两缕碎发被晚风拂起。

【服装与体态】柔和梨形的丰盈匀称体态，肩颈舒展、腰胯过渡自然；穿石榴红高腰长裙、象牙白内衫与浅金披帛，服装完整、不透明、合身而不紧勒。主面料为柔亮丝绸与轻薄罗，金线只收在裙腰缘饰；丝绸随停步形成连续窄高光，披帛在晚风中向身后展开柔和弧线，不真空贴体。

【叙事动作】右手正在放低团扇，完整圆形扇面微微转向身侧；左手轻提裙侧以避开落花，重心由前脚移回后脚，肩部因停步微微回收。她没有直视观众，而是看向脚步来源；下一拍像是将转身确认来人。

【空间与环境】前景只用一簇轻微失焦的深红牡丹引导视线，中景承载人物和放扇动作，后景为暮色中的曲廊、稀疏宫灯和正在离席的模糊人影。晚风让花影落在衣袖上，几片花瓣越过裙摆，环境不是静止布景。

【构图与镜头】9:16 竖版，大腿中部景别，人物从高髻到裁切处占画面高度约 88%，脸部清楚可辨；人物接近中轴并略向右偏，左侧为她的视线和来人方向留白。平视略低机位，约 80mm 人像透视，中等浅景深，完整保留高髻、脸、双手、团扇和高腰裙上部结构，双眼为第一对焦层。

【光色与成像】暮春暖金侧光从左后方穿过花枝，石阶与浅色墙面提供柔和正面补光，脸部明亮而不过曝；石榴红为主色、象牙白为辅色、朱红花钿与暖金珠饰作少量点睛。真人摄影质感，暗部保留织物颜色，金属只形成小面积亮点。

【必须保留 / 避免】必须保留听见脚步后的停步瞬间、正在放低的团扇、仍在余摆的发饰和左侧视线留白。避免未成年感、裸露或透视、深 V 与刻意塑形；避免满头珠宝、现代影楼头冠、机械回眸、正面呆站、塑料皮、手指错误、发髻或双手被裁切。
```

## 标杆二：雨后勒马的侠女

```text
【画面命题】请生成一幅真人写实、克制电影感的古装动作人像：雨后的青石山道上，一位 25 岁、明确成年的东方侠女刚勒马停在浅水边；她先于马匹察觉竹林深处的异响，动作未完成，警觉中仍有长途跋涉后的微弱疲惫。

【人物辨识度】略长椭圆脸，颧骨与下颌线清楚但不过分锋利；利落平眉、清醒凤眼、自然挺直的鼻梁和颜色克制的唇。皮肤保留雨雾湿气、眼下淡影与鬓边粘住的一缕碎发，神态沉着，不用夸张怒目或冷脸模板。

【妆发饰品】长发高束成稳固马尾式发髻，以深色皮质发带和一枚小银扣固定，不佩戴摇晃繁重的发冠；耳侧只留小型古银耳饰。马骤停后，发尾和披风仍沿前进方向保留惯性。

【服装与体态】适中舒展骨架、轻度倒三角形的健美体态，肩背有力、腰胯利落、腿部稳定。穿黛青窄袖交领骑装、深灰护腕、暗红腰带和完整不透明的分层下装；粗纹绢与哑光皮革为主材质，银扣为唯一亮面点睛。衣服提供真实活动余量，不紧勒、不真空贴体。

【叙事动作】右手向后收紧缰绳，绳线有明确张力；左手按住剑鞘而未拔剑，拇指刚抵住护手。躯干随马停步略向后稳定，双腿贴合鞍具保持平衡，视线越过马耳投向竹林左前方；她仍稳坐鞍上，当前只呈现勒马与判断的一瞬。

【空间与环境】前景是一小片被马蹄踏开的浅水和飞溅泥点，中景为人物、马、缰绳与剑的完整关系，后景竹林被雨雾分成深浅层次。湿青石反射冷天光，马的前蹄刚落水，鼻息在凉空气里形成极淡白雾；竹叶滴水，披风下缘带有真实湿重感。

【构图与镜头】9:16 竖版中远景，人物与马沿画面纵向形成完整轮廓并占画面高度约 85%，左前方为异响来源和有限运动留白；略低机位、约 50mm 自然透视，快门感冻结主要动作但允许发尾和水滴轻微运动模糊。对焦先落人物双眼，再落握缰手与马头，马腿、鞍具和人物腿位完整可信。

【光色与成像】阴雨天冷灰漫射光为主，湿路面从下方提供微弱反射补光，让脸部和眼睛清楚可读；黛青为主色、深灰为辅色、暗红腰带为唯一暖色锚点。皮革吸光、湿石反光、粗纹绢在褶皱转折处出现细弱亮边，整体低饱和但不死黑。

【必须保留 / 避免】必须保留勒紧的缰绳、按剑未拔、马蹄入水与左前方警觉视线。避免静态摆拍、双手失去任务、马具缺失、人物悬浮、马腿畸形、披风逆物理飘动；避免现代紧身服、裸露或透视、敏感部位焦点、廉价仙侠光效、过度锐化和暗脸。
```

## 标杆判断

标杆不是要求复制固定措辞，而是检验四件事：用户能一眼看出发生了什么；人物为什么这样穿和这样动；环境与光为什么呈现成这样；删掉任何一个视觉锚点都会明显改变画面。

## 标杆三：脸部优先的明艳贵女

```text
【画面命题】请生成一幅 9:16 竖版、真人写实的盛唐灵感半身人物画：雨后的曲廊窗边，一位 23 岁、明确成年的东方贵女推开半扇木窗，刚看见庭中被雨打落的牡丹；她原本神情从容，抬眼的一瞬却有真实的惊喜，画面首先让人看见她明艳贵气而有生命力的脸。

【人物辨识度】采用单一“明艳贵气”方向。柔和饱满的鹅蛋脸，舒展长眉与清亮杏眼形成主对比，两只眼睛完整可见、形状稳定、视线一致；深色瞳仁里各有来自同一窗光的小而清楚的高光。鼻梁自然，鼻头有真实体积，唇峰清晰，以饱和而不荧光的朱红唇作为唯一高纯度色彩焦点；白皙皮肤保留细小绒毛、唇纹和自然明暗，不磨成发光瓷面。

【妆发饰品】乌发梳成轮廓饱满的唐风高髻，只用一支金质花树钗和一对小珍珠耳坠；眉心花钿小巧，不压缩眉眼空间。鬓边碎发只停留在脸部外轮廓，不穿过眼睛、鼻子和嘴唇；耳坠因她刚抬头产生极轻余摆。

【服装与体态】肩颈舒展、上身衣着轮廓自然协调；象牙白内衫外叠石榴红高腰裙与浅金披帛，服装完整、不透明、合身而不紧勒。丝绸在肩部转折处出现柔窄高光，罗质披帛只表现细密织纹与边缘光，不透出身体细节；金线仅用于领缘的一处工艺焦点。

【叙事动作】右手扶着推开的窗框，指节自然受力；左手在胸腹前方接住一片刚被风吹入的牡丹花瓣。身体微微向窗外靠近但不刻意扭腰，视线落在庭中花枝而非空洞看镜头；下一拍像是会露出更明显的笑意。

【空间与环境】人物脸和双手占据主要视觉重量；竖向背景只保留一段向上延伸的湿润曲廊、深绿叶片与少量落花，作为她视线和窗外空间的证据。窗外冷湿空气轻轻带动披帛和耳坠；前景不放花枝、薄纱、帘幕或烟雾，不让任何元素穿过面部。

【构图与镜头】9:16 竖版，腰上至大腿中部中近景，人物从高髻到裁切处占画面高度约 90%，脸部清楚可辨；人物接近中轴并略向右偏，左侧保留她看向庭中牡丹的有限叙事留白。约 80mm 人像透视，平视，近正面仅轻微转脸，足够景深让两只眼睛同时清晰。采用中等浅景深，眉眼、鼻尖、唇部和脸部轮廓自然清楚，动态模糊只允许出现在最远处花瓣和耳坠末端。

【光色与成像】大面积柔和窗光从左前方照亮眉眼和鼻唇，浅色墙面提供低强度正面补光，保证暗侧眼睛仍有层次；窗外冷青环境色轻轻分离发丝轮廓。象牙白为辅色、石榴红为主色、朱唇与少量暖金作点睛；脸部曝光优先，高光不过曝，真实摄影锐度，不使用 HDR、过度锐化或塑料磨皮。

【必须保留 / 避免】必须保留明艳贵气方向、两只眼睛同时清晰、朱红唇单点色彩、抬眼惊喜和接住花瓣的手。避免脸部过小、失焦、近眼清楚远眼模糊、左右眼视线不一致；避免发丝、花枝、披帛、雾气和阴影遮脸；避免网红模板脸、超大眼、尖下巴、现代浓妆、未成年感、裸露透视和敏感部位焦点。
```
