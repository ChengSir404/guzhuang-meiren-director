# 行为回归用例

使用真实请求独立运行，按意图与保持项检查，不以关键词命中代替行为验证。不需要生成图片来测试输出格式；出图效果应另行验证。

| 用例 | 请求 | 验收条件 |
|---|---|---|
| 默认九模块 | 写一位真人古装女子，在花廊里自然站着 | 恰好九个主标题、正确顺序，不擅自加短版；静态可成立 |
| 简单场景不扩展 | 九模块，普通花园人像，不要多余细节 | 不追加材质、环境、特效模块，不制造复杂机制 |
| 必要扩展 | 九模块仙侠，需详细交代三层星轨的空间交叉和发光范围，另列特殊效果 | 九模块完整，之后追加特殊效果；场景与动作中不重复整段特效 |
| 明确短版 | 一段话，成年东方女子现代制服，尖头高跟鞋，B～C，鞋色自由 | 单段保留要求，不补固定鞋色或另附九模块 |
| 固定平口 | 固定平口胸型，透明丝绸长袖覆盖肩部 | B～C基础只写一次，水平领口、不透明内搭、薄袖确实覆盖；不自动低V |
| 形状覆盖 | 固定胸型，但改水滴形，其他保持 | 水滴覆盖圆锥，不并列两种主轮廓，保留体积与自然重力 |
| 体积独立 | 只加B～C视觉体积，不改其他 | 不自动加圆锥、水滴或领口要求 |
| 未指定项主动设计 | 普通清雅古装人像，胸型眼型场景动作表情都由你搭配 | 九模块中形成具体协调方案；可选胸型和眼型，不自动套固定模板或杯码，不用“模型自由发挥”代替核心设计 |
| 衣装适配 | 宽松厚锦袍，胸型你搭配，静态站姿 | 可以选择自然轮廓，但不要求厚衣逐处贴体或显出精确形状；保留静态站姿 |
| 组合质量 | 给花卉主题自行搭配背景动作表情，不要随便拼 | 场景有具体空间关系，动作在该空间可执行，神态与动作相符，脸部可读；不能只有通用赞美词 |
| 明确保留自由 | 其他由你设计，但鞋色必须留给生图模型 | 主体方案明确，鞋色不指定，不把这一项自由扩大到所有核心项目 |
| 眼型匹配 | 写三种不同气质人像，眼型分别狐狸、丹凤、柳叶 | 逐个保留眼型，结构可辨，不加兽耳或绑定人格 |
| 明确眼睑 | 柳叶眼、内双，保持人物身份 | 内双与柳叶眼共存，不强改双眼皮或眼形 |
| 台面盘腿 | 整个人坐在宽台面上，盘腿收于身前，脚部可见 | 臀部与双腿均在台面，承重合理，不写腿垂地 |
| 二郎腿勾鞋 | 高背椅前半座，二郎腿，上方脚脚尖勾鞋 | 下脚支撑，上脚前掌留鞋内、脚跟离后帮；不改成沙发 |
| 自然站姿 | 正面自然站着，不抬腿、不拿道具 | 双脚落地，手自然，无额外剧情任务 |
| 局部表情 | 只把表情改俏皮，双眼都要清楚 | 轻微眉嘴变化，不单眼眨眼，不改动作服装 |
| 单侧配饰 | 只加一只脚踝上的脚链，保留鞋履 | 仅单侧，不自动赤足、改鞋色或露更多腿 |
| 去重复 | 上版托花微笑抬腿，这次全部换 | 改姿态家族、手部任务、表情与空间结构，不只改花名 |
| 历史未知 | 给一个从未用过的场景，但没有历史列表 | 可给新设计，不声称核对了所有历史作品 |
| 全身锁定 | 16:9人马全身，脸清楚 | 保留马腿、人物全身与画幅，清晰要求符合景别 |
| 严格侧脸 | 40岁、棕色肤色、水墨、1:1、严格侧脸 | 全部保留，不强求双眼或真人媒介 |
| 两段原稿 | 保留两段，只去重 | 不扩九模块，不加人物、道具或剧情 |
| 缺图 | 按未提供的参考图只换衣服 | 请求必要图片，不编造识别结果 |
| 团扇 | 修正合起圆形团扇，保留团扇 | 改成放低或转动，不写折叠扇骨 |
| 锁定冲突 | 正面胸像但背链必须完整可见，两者都不能改 | 简短指出冲突，不谎称同时满足 |
| 严格考据 | 南宋女装，给实物出处 | 查证权威资料，不能把幻想设定称复原 |

## 固定局部修复输入

请求：只改第二段光线，让脸清楚，只输出替换段。

第一段：35岁圆脸杏眼女骑手，黛青骑装，骑白马，人与马全身入画16:9，左手握缰右手扶鞍，侧身看向左前方。

第二段：夜晚竹林只有背后月光，脸在阴影中。

验收：补合理面光，保留夜晚、竹林、构图、身份、服装、马与手部动作，不凭空添加手持灯笼。

## 验证层级

- 包结构：`python3 scripts/validate_skill.py`，不调用模型。
- 实际提示词：记录请求、输出、日期与是否满足要求；独立用例不要读取其他用例答案。
- 出图对比：明确需要时另行运行；没有出图就不宣称效果已验证。

## 预设润色与连续修改回归

| 请求 | 验收条件 |
|---|---|
| 固定胸型只润色，不改设定 | 保留B～C视觉体积、自然圆锥轮廓、适中底部宽度、偏窄间距与自然重力，不改水滴形或添加年龄 |
| 固定平口、未另指定露肤，给独立成品 | 基础预设只出现一次，选择完整包覆；水平领口明确，不残留“可完整包覆或露肤”的分支 |
| 固定平口、透明外披，但肩袖必须不透肤 | 内搭与肩袖不透明，外层仍可透明；不能把半透明覆盖称为完全遮蔽 |
| 只改平直领口，体量形状保持 | 不触发整套固定平口胸型基础，不新增杯码或改圆锥形 |
| 固定预设、厚实宽松衣袍 | 保留衣服与体量，只写可见整体廓形，不用贴体或透视来显示具体胸型 |
| 固定胸型、平口和腰链合成一段，银链红宝石 | 原有体量、轮廓、水平领口与银链红宝石不丢；不套回玉坠，不机械拼接重复限制 |
| 只加右脚脚链，鞋裙保持 | 人物右侧单只脚链，不复制到左脚；脚踝被遮挡时说明可见性限制 |
| 以刚才采纳版为准，只把表情改俏皮 | 年龄、服装、构图等保持，不恢复弃稿，不顺带换脸 |
| 同一人物系列继续做三张，避免重复 | 身份辨识点不变，通过空间、姿态、光色等变化 |
| 正面静态肖像只修僵硬，不换姿势道具 | 只修关节、受力或神态，不添加剧情、道具或转侧身 |

新增用例须实际运行后才可判定通过；文本与包结构检查不代替成图验证。
