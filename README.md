# 古装美人提示词导演

为 ChatGPT 生图编写中文成年东方女性提示词，覆盖古装、仙侠、花卉、古今融合及明确要求的现代人像。真人质感与自然神态优先，按需调用分类库，不随机堆词。

未指定年龄时默认20岁、明确成年；用户明确指定其他成年年龄时优先采用用户设定，气质称呼不自动改变年龄。

## 默认输出：九模块

【画面目标】→【人物】→【面部与发型】→【服装与身材】→【表情】→【动作】→【构图与镜头】→【场景、光线与色彩】→【约束】。

保持顺序、同一信息只写一次。仅在确有必要时追加【材质细节】【环境细节】【特殊效果】，不改变九模块主结构。用户明确要求一段话、核心短提示、保留原格式或局部替换时优先遵从。

## 能力

未指定的胸型、眼型、背景、动作和表情由AI主动协调设计，先比较构思，再按九模块交付一套成品；不随机拼接词库、不以“自由发挥”代替核心设计。用户明确锁定项与局部修改范围保持优先。

- **7种胸部主轮廓**：圆锥、水滴、圆润、钟形、浅盘、细长、松弛自然；体积、间距、领口分开控制。未指定时可按体态、服装与姿态自主搭配，不机械调用固定模板。
- **12类眼型描述**：杏眼、圆眼、柳叶眼、丹凤眼、瑞凤眼、桃花眼、狐狸眼、睡凤眼、细长眼、上挑眼、微垂眼、小鹿眼；名称配可见结构，不固定同一套脸。
- **31种基础姿态**：13种坐姿、10种站姿、8种跪卧与动态结构；另有手部互动、脚踝、脚尖勾鞋与单侧脚链规则。
- **16类气质与神态**：可爱、俏皮、甜妹、御姐、清冷、温柔、慵懒等，转成具体眼神、眉部和嘴角变化。
- **场景变化与修复**：花卉融入空间，避免只换花名；保留复杂幻想背景中的真人质感；单项修复不擅自换脸换装。

这些名称是生成用的视觉描述，部分属于重叠的审美俗称，并非统一医学分类。内置知识要点与使用边界见 [sources.md](references/sources.md)。

## 固定预设

“固定胸型／固定丰满胸型”调用B～C视觉体积、自然圆锥型、柔软与重力感的基础预设；明确指定水滴形等其他形状时覆盖对应部分，不改变其他设定。

“固定平口胸型”继承基础预设，追加不透明抹胸与严格水平领口；自然露肤至多约四分之一，也允许完整包覆。透明丝绸外披、肩部薄袖按要求叠加，内搭仍不透明。完整定义见 [body-silhouette.md](references/body-silhouette.md)。预设会按当前衣装和景别展开为连贯段落：厚衣只写整体廓形，组合模板合并重复说明；只润色时保留体量、轮廓、领口与材质。普通“平直领口”要求不自动触发整套固定胸型。

## 安装与更新

首次安装到你的个人 skills 目录（路径按实际环境调整）：

```bash
git clone https://github.com/ChengSir404/guzhuang-meiren-director.git ~/.codex/skills/guzhuang-meiren-director
```

如果已安装目录本身是 Git 克隆：

```bash
git -C ~/.codex/skills/guzhuang-meiren-director pull --ff-only
```

若原来是复制安装，需用新版文件更新该目录，保留自己的修改。重新开启任务后确认 skill 可用；仓库更新不等于已有会话自动重载。
