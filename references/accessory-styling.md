# 腰链与身体配饰的按需搭配

用于用户要求配饰搭配、腰链、脚链、臂钏、肩链、背链或固定配饰模板时。饰品服务现有成年人物造型，不自动改变服装、体型、动作或构图。

## 先选主饰品，再决定是否辅助

- 默认一个主配饰，必要时加零至两处低调辅助；这是取舍参考，不是必须填满的数量。已有发簪、耳坠等也计入全身饰品预算。
- 用户只要求加腰链时只加腰链，不顺带添加脚链、臂钏与肩链。用户要求自由搭配时，从当前镜头可见且与动作相关的位置选择。
- 同一造型优先一种主金属色、一种点睛材质；主饰品复杂时，辅助使用简洁单件，不再叠加多层链、宝石、珍珠、铃铛与流苏。
- 用户明确保留的饰品不擅自删除。已有饰品较多时，先降低新饰品体积、层数与高光；不得以默认数量覆盖明确要求。
- 默认脸为第一观看目标，饰品亮点不遮挡五官、不压过眼神；用户明确拍配饰时才调整观看重点。

## 按服装与景别选择

| 配饰 | 适合的可见条件 | 结构与搭配要点 |
|---|---|---|
| 腰链 | 腰部入画，有裙腰或衣料固定位置 | 明确固定点、垂弧与一处坠饰；不缩腰、不悬浮、不穿入衣料 |
| 脚链 | 脚踝已入画且未被裙摆或靴筒遮住 | 坠饰可放外踝，避开鞋带与脚部接触位置；不自动改赤足或剪短裙摆 |
| 臂钏 | 上臂可见或原服装已有合适装饰位置 | 松紧适度，不陷入皮肤；宽袖覆盖时不要求透过布料看见 |
| 肩链 | 肩部结构可承载链条 | 指定衣料固定点与自然弧线，不自动改露肩款 |
| 背链 | 原构图已能看到背部 | 服从后领、背部衣料与固定点，不为了显示背链让人物转身或改露背 |
| 耳坠、步摇 | 面部近景或半身 | 与发髻结构相容，垂饰避开眼睛，作为主饰品时其他部位从简 |
| 手镯、戒指、指链 | 手腕与手部在当前画面可见 | 不干扰握剑、执笔或其他既定动作；指链需交代连接关系，不能用它掩盖手部结构错误 |
| 颈链、额饰、发链 | 领口或妆发已有合适空间 | 服从衣领与发髻，不自动加低领、改发型或叠满面部周围 |
| 腿链 | 仅用户明确要求且原服装、景别适合时 | 不自动提高开衩或拉近局部特写，不作为默认搭配 |

配饰被衣服遮住时允许不可见，不要求透明衣料。画面外的配饰不写微观细节；若用户明确要求它可见而又锁定不兼容的景别或遮盖，简短说明冲突并询问取舍。普通搭配直接省略不适合的候选项。

## 不把配饰请求扩成换装

添加腰链不等于授权露腰、低腰裙、镂空、缩腰或转腰；添加脚链不等于授权赤足、开衩或踮脚。成年人物的非色情化适度露腰、露肩可按用户明确设定处理，不由模板默认引入；衣服保持必要遮盖、不透视敏感部位。

严格考据时读 [历史妆造参考](historical-styling.md) 并核对具体时代与身份依据。没有依据的多层宝石腰链、肩链等写为古典灵感设计，不因“盛唐、敦煌”标签就宣称历史复原。

## 静态图中的动作与光

只写当前已有动作的一瞬：迈步后坠饰略偏向一侧、停步时短流苏尚有少量余摆；静止时自然下垂。不为了饰品添加旋转、抬腿等动作，不在单张图中罗列连续舞步。链体沿固定点受力，坠饰响应重力与惯性；不能让刚性臂钏像柔链一样大幅摆荡。

金属形成小面积反光，玉石与珍珠提供柔和反射。增强精致感优先调整材质、层次和可见性，不承诺更易通过审核、更稳定出图或修复手部畸形。

## 固定模板

用户说“用固定腰链模板”或“用固定脚链模板”时，按当前衣服与景别适配一段，不同时加载另一套，不机械复制不成立的固定点。只改指定配饰段；未指定其他设定时保留原稿。

### 固定腰链模板

```text
腰间衣料外佩戴一条纤细金色腰链，固定于裙腰两侧，前方自然垂成柔和弧线，腰侧悬一枚小巧玉坠。链条顺应重力贴近衣料，不悬浮、不穿模、不收紧腰身；金属仅形成少量细碎高光，与现有首饰呼应。保持原有服装覆盖、腰线、姿态与构图。
```

### 固定脚链模板

仅在脚踝原本可见时采用：

```text
脚踝佩戴一条纤细金色脚链，外踝侧悬一枚小巧玉坠，链条留有自然余量，避开现有鞋履边缘与鞋带。坠饰顺应重力下垂，金属只呈少量柔和亮点，不改变原有裙长、鞋履、站姿与构图。
```

## 少量搭配示例

- 清雅半身：玉簪为主，小耳坠辅助；不追加画面外的腰链、脚链。
- 腰部入画的古典融合造型：细腰链为主，简洁耳饰辅助；已有复杂头饰时腰链降为无坠饰细链。
- 舞蹈灵感全身：选择腰链或脚链中的一个作主饰，另一部位不自动添加；依据原动作安排一处余摆。

成品只输出选定的一套，示例不是固定套餐。
