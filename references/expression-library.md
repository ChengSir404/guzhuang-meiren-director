# 表情与气质库

“御姐、甜妹、仙女”是气质方向，不是单块面部肌肉。每次选一种主气质，落成一个眼神变化与一个嘴角或眉部变化；动作与事件决定表情强度，不机械堆“可爱俏皮妩媚高冷”。以下为原创表演提示，不是心理诊断或从长相推断性格。

| 方向 | 可直接用的神态 | 避免 |
|---|---|---|
| 可爱 | 双眼自然明亮，嘴角轻扬，面颊放松 | 鼓腮嘟嘴、瞪大眼、幼态化成为默认 |
| 俏皮 | 一侧眉梢轻挑，眼神带笑，嘴角压住一点笑意 | 挑眉、眨眼、咬唇、歪头四件套同时发生 |
| 甜妹 | 目光清澈亲近，轻笑露出少量牙齿 | 露齿过多、夸张营业笑、未成年感 |
| 单纯明快 | 像刚听懂一句有趣的话，眼神微亮，笑容自然展开 | 将“傻白甜”写成呆滞或空洞 |
| 御姐／成熟自信 | 目光稳定看向镜头，下颌放松，嘴角带克制浅笑 | 高抬下巴遮眼、愤怒凝视、强制咬唇 |
| 明艳妩媚 | 眼尾自然含笑，视线专注，唇角柔和上扬 | 眯眼到失焦，所有动作都做成挑逗 |
| 清冷 | 眉眼舒展而克制，目光清醒，双唇自然轻合 | 死板僵脸、眼神失焦、强行皱眉 |
| 温柔 | 眼神柔和，嘴角轻轻舒展，下颌松弛 | 过度柔焦，低头导致五官不可见 |
| 高贵从容 | 平视而稳定，眉部放松，唇角有很浅的笑意 | 翻白眼、夸张傲慢、整张脸无表情 |
| 慵懒 | 上眼睑略放松但仍看清瞳仁，唇部自然舒展 | 闭眼、醉态、头颈失去支撑 |
| 英气专注 | 视线聚焦动作目标，眉间略收，嘴唇轻合 | 战斗时仍固定甜笑、咬牙切齿过度 |
| 惊喜 | 眉梢稍抬，眼神短暂亮起，嘴唇轻分 | 圆睁双眼、大张嘴的惊吓脸 |
| 害羞 | 目光短暂偏开后带笑，唇角微收，脸仍可见 | 头发遮脸、埋头、极端幼态 |
| 好奇 | 眉部轻提，视线落在对象上，唇部放松 | 不顾对象方位硬看镜头 |
| 沉思／怅然 | 视线稍远，眉间微收，嘴角放松或轻收 | 自动加泪、浓烈痛苦和大幅皱眉 |
| 坚定／庄严 | 目光稳定，唇线自然收合，头颈挺而不僵 | 紧咬牙、抬鼻孔或塑料英雄脸 |

## 细微变化按需使用

- 闭口浅笑、微露齿笑、忍笑是不同状态，选一种；“唇微分”与“紧闭双唇”不可同写。
- 轻咬下唇仅按用户要求或明确适配的情绪使用，不作通用魅力模板；不叠张嘴露齿。
- 单眼轻眨会遮住一侧眼睛，与“双眼完整清楚可见”冲突；用户未授权时改成眼尾含笑。
- 轻微歪头也不是默认选项；头颈随姿态自然，避免每张同角度歪头。
- 神态最好由正在做的事产生：落子后的笑意、遇到意外光影的惊喜、撑住窗时的专注。静态肖像无需虚构来人或剧情。
- 用户要求“全部换”时切换主情绪或表达方式，而非给“微笑”换一组同义词。
