# ChatGPT 文生图提示词架构

用于把造型想法转成安全、层次清楚、可直接交给 ChatGPT 文生图的中文成品。

## 指令优先级

参考图身份 / 当前明确要求 > 朝代与身份 > 场景动作 > 项目默认审美配置 > 通用画质词。

冲突时保留高优先级项，删除低优先级冲突描述，不把两套互斥特征同时交给模型。

## 默认九层结构

除非用户要求精简，按以下顺序输出，每节只解决一种问题：

1. **【画面命题】** 用 1–2 句写清人物身份、时代气质、当下事件、决定性瞬间和情绪潜台词；开头直接使用“请生成”。
2. **【人物辨识度】** 明确 20–25 岁成年东方人物；先选择明艳贵气、清艳含蓄、明媚灵秀、冷艳英气或圣洁华美中的一个方向，再选择 3–4 个可见的脸部、皮肤与生命感特征，写清一种基础眼型、眉眼主对比、一个色彩焦点和瞬时眼神，不用“杏眼与丹凤眼之间”式混合标签。
3. **【妆发饰品】** 把妆容、发髻、主发饰和少量辅助饰品写成一套秩序，并说明垂饰如何响应动作。
4. **【服装与体态】** 先写主时代轮廓与叠穿，再写主辅点睛色、2 种主面料、1 个工艺焦点，以及完整衣着下的自然身材和衣褶重力。
5. **【叙事动作】** 先确定事件或声音来源，再明确主道具、双手职责、重心、视线、头肩响应、瞬时表情和下一拍动作；静态肖像也必须有微动作或刚刚发生的痕迹，所有方向关系保持一致。
6. **【空间与环境】** 用前景一个引导元素、中景人物事件、后景时空证据建立纵深；至少写一项环境对人物或道具的反馈。
7. **【构图与镜头】** 说明画幅、景别、主体位置、机位、焦段感、景深、对焦层与留白方向；用户未指定时统一采用 9:16 竖版。美貌优先时使用腰上至大腿中部中近景、人物占画面高度约 85%–92%、脸部约占 18%–22%、近正面、70–85mm 人像透视和中等浅景深，双眼同焦；只写镜头实际可见的细节。
8. **【光色与成像】** 写清主光来源、柔和辅光、脸部曝光、主辅点睛色关系、材质如何受光，以及真人写实或其他指定媒介质感；脸部不得被雾、发丝、薄纱、道具、斑驳阴影、强逆光或运动模糊破坏。
9. **【必须保留 / 避免】** 先列 2–4 个必须保留的画面锚点，再列 3–8 个与当前构图直接对应的失败约束；不要复制通用负面词大全。

纯人物无背景时仍写明极简纯色/透明背景、轮廓分离与禁止多余场景，不删除空间和光线说明。

## 安全改写

- 默认写“明确成年的东方古典美人”或语境化替代称呼，不使用幼态、少女感与成人曲线并置的表达。
- 将“又纯又欲”改写为“圣洁端庄为主，柔美女性魅力藏在眼神、体态、珠玉和衣料中”。
- 将直接胸型要求改写为安全的衣着轮廓。例如：“水滴形”写成“上部过渡柔和、下部自然丰盈的水滴形衣着轮廓”；“圆盘形”写成“底盘宽缓、前突克制、过渡平顺的浅盘形衣着轮廓”。始终补充“与胸廓和整体体态协调，通过完整不透明、合身不紧勒的古装剪裁自然呈现”。
- 用户未明确要求胸型时，不主动点名具体胸型，只写整体体态和上身衣着轮廓。若 ChatGPT 拒绝直接胸型描述，降级为“上身衣着轮廓自然协调，服装完整不透明”，不以替换近义词的方式反复试探限制。
- 将露胸、透视、挤压、敏感部位特写等要求移除，改用颈部、肩颈姿态、衣料质感、色彩与珠宝建立吸引力。
- 将真实宗教对象的性感化请求改为“受相关造像服饰和审美启发的成年东方女子”。
- 负面约束明确加入：不要裸体、不要走光、不要透视敏感部位、不要色情姿势、不要性暗示、不要以胸部或臀部为画面焦点。

## 可执行写法

- 用行为替代抽象词：不只写“动作自然”，而写“右手提灯、左手接住纸灰，重心落在后腿，前脚将要迈出”。
- 用结构替代价值判断：不只写“高级服装”，而写“月白罗衫、浅金缘饰、暗纹集中在袖缘，丝料柔和垂坠”。
- 每个重点只写一次；画质词不能代替造型设计。
- 使用一个确定动作，不给“托花或抚琴或扶衣带”之类多选题。多个方案应拆开。
- 这一规则同样适用于脸型、眼型、唇色、发髻、簪饰、服装颜色、纹样、面料、场景和镜头：成品只交付一套已经决定的组合，不把设计选择留给图像模型。
- 不把“脸部清晰、真实皮肤、双眼对焦”等同一要求分散重复到五个章节。人物层定义脸，镜头层定义对焦，结尾只保留最关键的一次失败约束。
- 道具必须有物理关系：剑有握法与重心，琴有指位与案面，马有缰绳、鞍具、腿位与运动方向。
- 负面词与正面指令对应。例如要求完整保留发冠和双手，再补“不要裁掉发冠、不要遮挡双手”。
- 每一段至少包含一个因果联系，不只并列名词。例如“她刚勒住马，因此肩背微收、右手缰绳绷紧、披风沿运动反方向扬起”。
- 把“电影感”拆成可见结果：决定性瞬间、明确光源、受控景深、真实材质、前后景遮挡与克制色彩，而不是单独堆一个风格词。
- 提示词总长度服从画面复杂度。默认每层 1–2 句，不另设“细节强化”复读段；任何细节若不会改变画面就删除。

## 自动补全算法

1. 从主体词判断人物原型，再写出“身份 + 事件 + 情绪潜台词”的一句画面核。
2. 选择一个美貌方向、一种基础眼型与一组眉眼主对比；若美貌优先，先在 9:16 竖版中确定中近景、足够大的人物与脸部占比、双眼同焦和无遮挡面光。
3. 选择一种主形态语言：圆润流动、纵向清雅、利落斜线、端方秩序或冷暖幽微。
4. 选择与身份和动作相符的身高感、骨架、身材类型与安全衣着轮廓；服装结构优先于曲线展示。
5. 选择一个主道具或天然组合，先定位事件来源，让来源与道具共同决定双手、重心、视线、头肩方向和构图留白，再确定动作转折点与下一拍。
6. 选择一个主时代气质、主辅点睛三色、2 种主面料和 1 个工艺焦点，删除其余竞争元素。
7. 用一个前景引导物、一项后景时空证据和一项环境反馈建立空间，而不是罗列景物；前景不能遮脸。
8. 根据动作和画幅确定主体位置、留白方向、机位、焦段感、焦点与材质受光；运动模糊不得落在面部。
9. 压缩为 5–8 个高价值视觉锚点，最后加入与当前构图直接相关的安全和失败约束。

示例联动：

- “清冷侠女” → 剑或马 → 竹林/山道 → 警觉侧听或翻身下马 → 利落窄袖与稳固发髻。
- “温柔才女” → 书卷与笔 → 临窗书房 → 落笔后抬眼 → 清雅褙子/长裙与简簪。
- “盛唐贵女” → 团扇或牡丹 → 宫苑花径 → 缓步收扇 → 高髻、披帛、明艳暖色。
- “志怪美人” → 灯笼 → 雾夜古街 → 提灯前行 → 月白暗红、古银发饰、冷月暖灯。

## 输出模式

### 完整版（默认）

交付 9 个分区的导演式中文成品。段落之间有因果关系，结尾含精炼安全约束；不要在成品前后反复解释。

### 精简版

压缩成一个连贯提示词或不超过 6 段：画面核；人物与造型；动作道具；空间镜头；光色材质；关键约束。保留成年身份、安全衣着、决定性瞬间和主要视觉锚点。

### 基于参考图

先在心中划分“保持”和“改变”，成品中直接表达：保持人物身份、脸和未要求改变的部分；只改变指定妆造、动作、背景或光线。不要让场景参考污染人物身份。

## 质检清单

- 是否明确 20–25 岁、成年、东方人物（用户另有要求除外）？
- 是否用具体五官、皮肤与神态表现美，而非只写“绝色”？
- 是否选择了单一美貌方向，并用眉眼对比、一个色彩记忆点和瞬时眼神形成惊艳感？
- 当前景别是否足以看清所写的五官，双眼是否同时可见、同焦且无遮挡？
- 用户未指定其他比例时是否使用 9:16 竖版，并防止人物因展示高髻、长裙或庭院而缩小脸部？
- 是否一句话就能说清人物身份、当下事件与情绪潜台词？
- 是否存在明确的第一、第二、第三视觉锚点，而不是所有元素平均用力？
- 是否符合 ChatGPT 安全边界：完整不透明服装、非色情动作、无敏感部位焦点？
- 身高感、骨架、身材类型、胸部衣着轮廓和四肢比例是否互相协调，是否避免极端组合？
- 朝代、身份、发髻、首饰、妆容、衣服和道具是否同一语境？
- 是否先服装结构后身材曲线，衣料符合重力而非真空贴体？
- 主道具是否真正参与动作与叙事，而非装饰堆砌？
- 环境是否提供时空证据和动作反馈，而非通用古风壁纸？
- 表情与动作是否分别具体，双手有合理任务，重心可信？
- 事件来源、眼神方向、头肩转角、重心变化和构图留白是否指向同一空间关系？
- 是否避开 45 度模板、机械回眸、固定右侧构图与影楼感？
- 脸是否为第一对焦层，暗场是否有合理补光？
- 面部是否避开运动模糊、极浅景深、强逆光、雾气、花影、头发、薄纱和道具遮挡？
- 负面约束是否精炼、相关、不重复？
- 是否清除了“或、可选、可以加入”等未决分支，并把重复要求合并到唯一对应层？
- 是否控制在 5–8 个高价值细节锚点，删掉镜头不可见或不改变画面的描述？
