# ChatGPT 文生图提示词架构

用于把造型想法转成安全、层次清楚、可直接交给 ChatGPT 文生图的中文成品。

## 指令优先级

参考图身份 / 当前明确要求 > 朝代与身份 > 场景动作 > 用户个人默认审美 > 通用画质词。

冲突时保留高优先级项，删除低优先级冲突描述，不把两套互斥特征同时交给模型。

## 默认完整结构

除非用户要求精简，按以下顺序输出，每节只解决一种问题：

1. **【画面主题】** 人物、事件与核心气质。
2. **【主体人物】** 20–25 岁成年身份、东方特征、社会身份和性格。
3. **【五官与皮肤】** 可见特征、辨识度、真实肤质与对焦要求。
4. **【妆容与眉心】** 眉形、唇色、胭脂、花钿/额饰及时代匹配。
5. **【发型与发饰】** 发髻结构、真实发丝、主发饰、辅助饰品与摆动关系。
6. **【饰品体系】** 耳、颈、腕、腰、脚按身份选择，不默认全用。
7. **【身材与比例】** 先整体体态，再写安全衣着状态下的自然曲线与四肢比例。
8. **【服装结构与材质】** 形制、叠穿、领袖腰裙、颜色、面料、工艺与完整遮盖。
9. **【人物道具】** 主道具、与身份的关系、真实握持或接触方式。
10. **【表情】** 眼神、嘴角、呼吸感和具体情绪。
11. **【动作与姿态】** 双手任务、头肩关系、重心、腿脚、下一拍动作和衣饰受力。
12. **【构图与镜头】** 比例、景别、位置、机位、焦段、景深和不能裁切的部位。
13. **【场景与背景】** 时代空间、前中后景、天气及人物与环境关系。
14. **【光线、色彩与质感】** 主辅光、冷暖、脸部曝光、材质反射与成像风格。
15. **【细节强化与负面约束】** 当前最易失败的脸、手、身体、衣料、饰品、构图、安全与风格问题。

纯人物无背景时仍写明极简纯色/透明背景、轮廓分离与禁止多余场景，不删除空间和光线说明。

## 安全改写

- 默认写“明确成年的东方古典美人”或语境化替代称呼，不使用幼态、少女感与成人曲线并置的表达。
- 将“又纯又欲”改写为“圣洁端庄为主，柔美女性魅力藏在眼神、体态、珠玉和衣料中”。
- 将直接胸型要求改写为“身材丰盈匀称，胸部自然丰满、圆润柔和且与胸廓协调，通过完整不透明、合身不紧勒的古装剪裁自然呈现”。
- 将露胸、透视、挤压、敏感部位特写等要求移除，改用颈部、肩颈姿态、衣料质感、色彩与珠宝建立吸引力。
- 将真实宗教对象的性感化请求改为“受相关造像服饰和审美启发的成年东方女子”。
- 负面约束明确加入：不要裸体、不要走光、不要透视敏感部位、不要色情姿势、不要性暗示、不要以胸部或臀部为画面焦点。

## 可执行写法

- 用行为替代抽象词：不只写“动作自然”，而写“右手提灯、左手接住纸灰，重心落在后腿，前脚将要迈出”。
- 用结构替代价值判断：不只写“高级服装”，而写“月白罗衫、浅金缘饰、暗纹集中在袖缘，丝料柔和垂坠”。
- 每个重点只写一次；画质词不能代替造型设计。
- 使用一个确定动作，不给“托花或抚琴或扶衣带”之类多选题。多个方案应拆开。
- 道具必须有物理关系：剑有握法与重心，琴有指位与案面，马有缰绳、鞍具、腿位与运动方向。
- 负面词与正面指令对应。例如要求完整保留发冠和双手，再补“不要裁掉发冠、不要遮挡双手”。

## 自动补全算法

1. 从用户主体词判断原型：贵女、侠女、才女、琴师、女将、敦煌灵感、志怪女子等。
2. 选择最匹配的一项主道具；若主体已经有强动作，则可不加道具。
3. 让道具决定动作和表情，再让动作决定服装宽窄、发饰稳定方式和场景空间。
4. 选择一个主时代气质与一组配色，避免跨时代元素无序混搭。
5. 补齐前中后景与光线，让背景支持人物而不抢视觉中心。
6. 最后加入与该构图直接相关的安全和质量约束。

示例联动：

- “清冷侠女” → 剑或马 → 竹林/山道 → 警觉侧听或翻身下马 → 利落窄袖与稳固发髻。
- “温柔才女” → 书卷与笔 → 临窗书房 → 落笔后抬眼 → 清雅褙子/长裙与简簪。
- “盛唐贵女” → 团扇或牡丹 → 宫苑花径 → 缓步收扇 → 高髻、披帛、明艳暖色。
- “志怪美人” → 灯笼 → 雾夜古街 → 提灯前行 → 月白暗红、古银发饰、冷月暖灯。

## 输出模式

### 完整版（默认）

交付 15 个分区的中文成品，结尾含精炼安全负面提示。不要在成品前后反复解释。

### 精简版

压缩成 7 段：主题人物；脸与体态；妆发饰品；服装；道具；表情动作；镜头环境与关键避免项。保留成年身份、安全衣着、主服装、主道具、关键动作和主要失败约束。

### 基于参考图

先在心中划分“保持”和“改变”，成品中直接表达：保持人物身份、脸和未要求改变的部分；只改变指定妆造、动作、背景或光线。不要让场景参考污染人物身份。

## 质检清单

- 是否明确 20–25 岁、成年、东方人物（用户另有要求除外）？
- 是否用具体五官、皮肤与神态表现美，而非只写“绝色”？
- 是否符合 ChatGPT 安全边界：完整不透明服装、非色情动作、无敏感部位焦点？
- 朝代、身份、发髻、首饰、妆容、衣服和道具是否同一语境？
- 是否先服装结构后身材曲线，衣料符合重力而非真空贴体？
- 主道具是否真正参与动作与叙事，而非装饰堆砌？
- 表情与动作是否分别具体，双手有合理任务，重心可信？
- 是否避开 45 度模板、机械回眸、固定右侧构图与影楼感？
- 脸是否为第一对焦层，暗场是否有合理补光？
- 负面约束是否精炼、相关、不重复？
