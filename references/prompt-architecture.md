# 输出架构

## 明确要求时才使用一段话与核心短提示

仅当用户明确要求“一段话／简短一段”时，输出一段精简成品：真人/媒介与画幅 → 成年人物 → 关键服装/胸型（仅按需） → 主要动作与表情 → 必要场景和面部清晰要求。没有必要的项目就省略，不规定固定字数，不为了“短”丢掉明确要求。

“核心短提示”只留人物、场景、关键服装、主要动作、必要表情与氛围；配色、镜头数值、首饰细项交给模型。不同时附长短两版，除非用户要求。

## 九模块固定模板

默认使用下列九模块标题；“按模板”“之前模板”“九模块／9个模块”也指同一结构。顺序不变，不加编号。沿用用户已提供的九模块结构。通常每模块1～2句；服装等复杂内容按需扩展。不要为了填满标题创造无关设定。

| 标题 | 唯一归属的信息 |
|---|---|
| 【画面目标】 | 画幅、媒介、主题与画面整体目标 |
| 【人物】 | 年龄、成年身份、整体气质与人物定位 |
| 【面部与发型】 | 脸型、眼型、真实肤质、发型与头饰 |
| 【服装与身材】 | 衣服、体态、明确要求的胸型、领口、外披、鞋履与身体配饰 |
| 【表情】 | 目光、眉眼和嘴角的当前神态 |
| 【动作】 | 一个当前姿态、必要的支撑点与手脚动作 |
| 【构图与镜头】 | 景别、朝向、对焦、人物和环境的位置关系 |
| 【场景、光线与色彩】 | 空间结构、植物、真实光源、必要色彩联系 |
| 【约束】 | 本图最易失败的少数限制，不复述所有正向内容 |

同一信息只出现一次：年龄不进胸型段，表情不混入发型段，光源不在三个模块反复写。固定胸型在服装模块展开，不能只留“按固定胸型”让独立生图模型猜。

## 整理、局部修复与参考图

保留原稿段数，除非用户要求改格式。局部修改只给替换段；要求完整可复制版时将修改合回全文。参考图用一句前缀交代各图职责、保持项和改变项；不存在的图不编造。成品只保留选定方案，不留颜色与姿势的未决选项。

## 按需追加模块

只有主模块确实无法清楚容纳关键内容时，才在九模块之后追加相关模块；保持九个主标题的相对顺序完整。普通人物、单一面料和常规花庭不需要附加模块。

- 【材质细节】：用于关键多层织物、特殊金属或复杂受光机制；服装模块保留结构，具体纹理与反光移到本模块，只写一次。
- 【环境细节】：用于复杂空间尺度、镜像关系或多层建筑定位；场景模块保留概貌，把必要的空间关系移到本模块。
- 【特殊效果】：用于仙侠法术、星轨、光幕等核心视觉效果；交代作用范围、遮挡与光照，不覆盖面部，不把人物变成CG质感。

附加模块不是必填，也不因“仙侠”自动追加。不得为增加模块而重复原句、堆装饰或新增无关剧情。
