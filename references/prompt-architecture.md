# 提示词架构与输出格式

遵循 [控制工作流](control-workflow.md) 的统一优先级。默认值以 [审美配置](personal-aesthetic.md) 为准。

## 输出模式

- 新建：默认连贯完整提示词，画面复杂或用户希望分区时用导演版。
- 整理：保留原稿段落与字数约束，只做必要修正。
- 精简：按指定字数、段数压缩，无须保留标题；未指定长度时只保留形成画面的关键内容。
- 局部修复：有原稿时提供替换段落并说明修复范围；没有原稿、需要独立使用或用户要求时给完整版本。
- 参考图：前置简短职责说明，指出保持项与允许改变项。

## 九层检查与可选导演版

九层用于检查覆盖，不要求每层都输出，不为填满分区新增内容。使用分区时每节只保留与画面有关的信息：

1. **画面命题**：主体、媒介、景别和第一观看目标；故事题材补当下事件，静态肖像允许无剧情。
2. **人物辨识度**：成年身份、已指定或新设计的五官特征与神态；身份参考存在时保持五官，不套默认脸。
3. **妆发饰品**：发髻结构与主饰品，允许素发无饰。
4. **服装与体态**：时代轮廓、叠穿、主材质、工艺与自然衣褶；不主动细分胸型。
5. **动作**：当前可见的手部、视线和重心；无道具、静态姿态也可成立。只写一个可见瞬间，不写未来动作分支。
6. **空间**：背景与人物的位置和光影联系；纯色或透明背景不追加场景与前景。
7. **构图镜头**：画幅、景别、对焦与留白；指定侧脸只检查可见眼睛，指定全身不改为半身。数字比例只是参考，不制造与景别矛盾的精确要求。
8. **光色材质**：光源、色彩关系、织物受光与指定媒介。用足够的景深覆盖面部，而不是要求鼻尖、双眼、嘴唇位于同一几何焦平面。
9. **保留与避免**：仅写本次保持项和最相关的失败约束，不重复长串通用负面词。

同一要求放在对应层，不在人物、镜头、光线和结尾反复展开。细节数量与段落长度服从用户要求及画面复杂度。

## 安全表达

本项目创作明确成年、衣着完整、不透明、非色情化的人物。用肩颈姿态、完整服装、材质、珠玉与眼神表达魅力，不以胸臀为画面焦点。

用户未要求胸型时写“上身衣着轮廓自然协调”即可；有相关要求时按 [衣着轮廓](body-silhouette.md) 表达。涉及宗教灵感与女性魅力时，以受造像服饰启发的成年人物表达非性化审美意图。若生成平台拒绝，应调整为适用的整体造型描述，不替换敏感词反复试探。

## 可执行性

道具要符合真实结构：团扇可放低、抬起、转动或收至身侧，不能折叠扇骨；折扇才有开合动作。动作的视线、重心和衣料反应应与同一空间事件相符；风力与惯性需要区分，不机械套“运动反方向飘”。

成品中的设计选项要确定；不要把“禁止裸露或透视”这类正常语法当成未决分支。严格考据依据可放在提示词外，普通创作不输出内部检查表。
