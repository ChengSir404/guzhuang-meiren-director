# 输出架构

## 明确要求时才使用一段话与核心短提示

仅当用户明确要求“一段话／简短一段”时，输出一段精简成品：真人/媒介与画幅 → 成年人物 → 关键服装/胸型（仅按需） → 主要动作与表情 → 必要场景和面部清晰要求。没有必要的项目就省略，不规定固定字数，不为了“短”丢掉明确要求。

“核心短提示”只留人物、场景、关键服装、主要动作、必要表情与氛围；配色、镜头数值、首饰细项交给模型。不同时附长短两版，除非用户要求。

## 默认：动态六模块（非强制）

普通人物写真默认按下表组织。简单任务可合并为四至五模块，复杂双人互动、武侠场景和特殊道具可扩展到七个以上；用户明确指定篇幅、格式、模块或原稿结构时优先遵守，不为凑数加入无关描述。

| 标题 | 负责的内容 |
|---|---|
| 【画面目标】 | 主题、正在发生的画面、媒介风格、核心氛围 |
| 【人物与面容】 | 成年状态、年龄、气质、脸型五官、眼型、发型发饰及真实肌肤质感 |
| 【服装与身材】 | 服装配色、剪裁、层次、面料、纹样、鞋履、身材比例；按明确要求调用固定胸型预设 |
| 【动作与表情】 | 姿态、朝向、支撑重心、四肢与道具接触、表情和视线；服务于当次主题 |
| 【构图与场景】 | 画幅、机位、景别、裁切、前中远景、场景物件、自然光照方向与色彩 |
| 【关键约束】 | 只针对本次易错的少量问题，如手足结构、腿长、道具尺寸、透视和光影材质一致性 |

标题与正文同一行，模块间只换行一次，不插空行、不编号。每模块通常一至两句，复杂姿态可以清楚交代支撑、重心与空间关系。每个事实只在最适合的模块说一次；固定胸型只在【服装与身材】展开。动作、表情、眼型与镜头不设常用固定套餐。先完成视觉设计，再精简表达。

## 整理、局部修复与参考图

保留原稿段数，除非用户要求改格式。局部修改只给替换段；要求完整可复制版时将修改合回全文。参考图用一句前缀交代各图职责、保持项和改变项；不存在的图不编造。成品只保留选定方案，不留颜色与姿势的未决选项。

## 固定预设的自然展开

通常按“可见外观 → 衣物或饰品结构 → 必要受力关系”连贯表达，避免反复重复“自然、柔和、协调、不透明”。只润色时保留体量、形状、领口、材质和位置，不借精简改设定。

组合胸型、平口和腰链预设时，将衣料、重力和保持说明合并；固定平口仍继承体态文件的基础预设，普通“平直领口”要求本身不触发整套胸型。选择明确的遮盖方式，不把模板中的条件分支原样留给生图模型。

## 按需合并与拆分模块

模块数量服从画面难度，复杂内容可拆出以下模块，也可直接合并到最相关主模块，不必须先填满六个。

- 【材质细节】：关键多层织物、金属或复杂受光。
- 【环境细节】：复杂空间尺度、镜像关系或建筑定位。
- 【特殊效果】：星轨、法术或光幕的作用范围、遮挡和照明。

额外模块不是必填，不为扩展而复述原有内容。
