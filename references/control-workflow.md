# 提示词控制工作流

用于在写九层成品前完成任务分流、约束排序、参考图职责分配和单变量修复。所有控制步骤默认在心中完成；除非用户要求分析，不把工作表和推理过程原样输出。

## 一、先判任务模式

| 模式 | 识别信号 | 核心动作 |
|---|---|---|
| 新建 | 只有人物、朝代、气质或一句画面想法 | 补齐必要的身份、事件、造型、空间与镜头 |
| 整理 | 用户已给出详细长提示词 | 清除矛盾、重复、未决分支和无效质量词，不另造新剧情 |
| 参考图引导 | 用户提供一张或多张图片，用于脸、服装、姿态、构图或风格 | 逐张分配角色，先写保持项，再写变化项和禁止迁移项 |
| 失败修复 | 用户提供失败出图或明确症状，如脸糊、像网红、动作僵 | 找到最上游原因，一轮只修一个主变量或一组强耦合变量 |

不要把“提供了图片”等同于“编辑这张图片”。用户只借用脸、服装、构图或氛围时，仍然是带参考图的新生成；只有明确要求保留原图并局部改变时，才采用编辑式的保持/改变表达。

## 二、建立内部画面契约

动笔前用以下字段在心中做一遍，不要求输出：

```text
任务模式：新建 / 整理 / 参考图引导 / 失败修复
不可变项：用户明确要求、参考人物身份、安全边界
唯一主意图：观众第一眼看见什么、感到什么
人物签名：一个结构辨识点 + 一个色彩记忆点 + 一个瞬时神态
决定性瞬间：正在发生的一拍
三级锚点：脸与眼神 / 人物轮廓与动作 / 环境证据
参考图职责：每张图提供什么、绝不带入什么
本轮修复变量：仅失败修复填写
装饰预算：最多 5–8 个会真正改变画面的细节
```

如果一句话无法讲清唯一主意图，说明画面还没有完成取舍。先删竞争元素，再补词。

## 三、约束优先级

按三档处理，低档不能覆盖高档：

1. **不可变项**：当前明确要求、参考人物身份、20–25 岁明确成年默认、安全边界、指定朝代与指定画幅。
2. **主驱动项**：脸部签名、当下事件、主动作、主道具、景别、对焦、主时代气质、核心光色。
3. **装饰项**：次要首饰、纹样、花瓣、雾、微粒、远景建筑和通用画质词。

发生冲突时，先删装饰项，再简化背景与次要造型，最后才调整主驱动项。不可变项只能由用户的新明确要求改变。

## 四、控制补全强度

- **一句概念**：允许补充一个人物身份、一个合理事件、一组服装妆发、一个主道具、一个环境和一套镜头光色。
- **已有清晰设定**：只补会解决构图、动作、光线或安全缺口的内容。
- **已有详细提示词**：以整理和压缩为主，不添加额外人物、道具、故事转折、品牌、风格名或新配色。
- **用户指定“保持原样”**：把保持项重复到本轮修复提示词中，不能只写变化项。

所有新增内容都必须回答至少一个问题：它是否帮助识别人物、解释动作、证明时代、建立空间或保证脸部质量？都不能则删除。

## 五、参考图角色映射

多图时逐张编号，每张图只承担一到两个清楚职责：

| 参考职责 | 可借用 | 默认禁止带入 |
|---|---|---|
| 人物身份参考 | 脸部几何、五官关系、肤色家族、年龄感、辨识痕迹 | 原背景、原服装、无关饰品 |
| 服装妆造参考 | 形制、叠穿、纹样位置、发髻和饰品结构 | 模特脸、姿势、摄影棚背景 |
| 姿态构图参考 | 身体朝向、手部任务、机位、景别、留白 | 人物身份、服装颜色、场景内容 |
| 色彩材质参考 | 主辅点睛色、明暗关系、织物与金玉质感 | 具体人物、建筑、道具 |
| 场景氛围参考 | 空间层次、天气、光源逻辑、环境反馈 | 人物脸、服装和动作 |

提示词前置写法示例：

```text
参考图职责：图1仅用于保持人物身份与五官关系；图2仅用于明制袄裙的结构和面料；图3仅用于庭院的光色与纵深。不得把图2、图3中的模特面孔、姿势和无关饰品带入成品。若参考冲突，以图1身份、用户当前文字要求、图2服装、图3环境的顺序为准。
```

单图同时承担身份和服装时，也要写清哪些可变、哪些不可变。不要笼统写“参考这张图”。

## 六、可见性测试与前置排序

每个重要词都应能转成以下至少一种可见结果：

- 五官结构或瞬时神态；
- 身体动作、重心或手部任务；
- 服装结构、材料、重力或受风方式；
- 镜头位置、景别、焦点或留白；
- 真实光源、阴影、反射或颜色关系；
- 能证明时代和地点的环境证据。

“绝美、顶级、高级、电影感、8K、大师级、氛围感”如果没有紧跟可见决定，应删除或改写。成品开头优先写主体、当下动作、景别和第一视觉锚点；模型必须先知道画面在拍谁、拍哪一瞬、最该看哪里。

## 七、单主变量修复

当用户说“差点意思”或提供失败出图时：

1. 若有图片，先看整幅构图，再看脸部区域；若只有文字反馈，选择能解释症状的最小原因。
2. 从人物身份、脸部、妆发、服装体态、动作、空间、镜头、光色中选出一个最上游失败层。
3. 把已经正确的部分写成不可变项。
4. 本轮只改一个主变量；只有强耦合时才允许成组修改，例如“脸太小”需要同时改景别、人物占比和背景密度。
5. 交付完整修复提示词，但不要偷偷重做其他层。

典型映射：

| 反馈 | 本轮主变量 | 应冻结 |
|---|---|---|
| 漂亮但没记忆点 | 人物签名：眉眼主对比 + 单一色彩焦点 + 瞬时神态 | 身份、服装、动作、场景 |
| 脸糊或太小 | 景别、人物占比、双眼同焦、面部用光 | 人物身份与核心造型 |
| 像网红脸 | 脸部结构辨识点、真实不对称、妆容年代感 | 年龄、动作、场景和构图 |
| 像影楼写真 | 决定性瞬间、非摆拍重心、方向性留白 | 人物与朝代造型 |
| 服装抢脸 | 脸周安静区、纹样密度、亮点面积 | 服装形制与人物身份 |
| 背景像贴纸 | 时空证据、遮挡纵深、环境反馈 | 人物、动作、服装和脸部光线 |

不要同时改脸型、发髻、服装、动作、背景和色调来“碰碰运气”。一次修复应让用户知道是哪项变化带来改善。

## 八、完成条件

- 开头已经说明主体、当下动作、景别与第一观看目标。
- 每张参考图都有角色，且写明不得迁移的内容。
- 详细输入只被整理，没有被擅自扩写成另一幅画。
- 抽象美感词都能被具体的脸、动作、光、材质或构图解释。
- 失败修复只改变一个主变量或一组强耦合变量。
- 不可变项在最终提示词中仍然可见，而不是只存在于分析里。
