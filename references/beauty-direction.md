# 眼型、脸部与真人质感

眼型名称不是严格互斥的医学分类。中文文学、美妆与民间资料用法不一；下表是为了生成可控而采用的视觉约定，不声称存在统一测量标准。已有身份参考时保留原眼型；只修清晰度不得换脸。

## 选眼型

未指定眼型时主动选择，不固定采用最常用的眼型。一次选一个主眼型，并补一个可见特征；结合脸型、妆发、场景和表情决定，不把“御姐=丹凤眼”“甜妹=大圆眼”写成固定映射。单眼皮、内双、双眼皮是眼睑结构，和眼型分开，可按需兼容；不强行给每种眼型规定单双眼皮。

| 眼型／风格名 | 本库采用的可见特征 | 可用的画面方向（不是人格判断） |
|---|---|---|
| 杏眼／杏仁眼 | 横向舒展、中央饱满，内外眼角自然收拢 | 温婉、清澈、知性；不固定超大眼 |
| 圆眼 | 纵向开合较明显，眼睑弧线圆润 | 明快、惊喜、可爱；保持成人五官比例 |
| 柳叶眼 | 眼裂细长，轮廓柔和，眼尾舒展 | 清雅、温柔、含蓄；不眯成一道缝 |
| 丹凤眼 | 眼形修长，内眼角收束，眼尾轻扬 | 英气、清冷、端丽；不夸张吊梢 |
| 瑞凤眼 | 修长但开合舒展，眼尾柔和上扬 | 温润、明艳、从容；不照搬瞳孔偏眼角等失真说法 |
| 桃花眼 | 上睑弧线柔和，眼尾稍长，笑时自然弯起 | 明媚、含笑、妩媚；不用厚重卧蚕替代眼型 |
| 狐狸眼 | 眼形狭长，内眼角清晰，外眼角轻提，眼神聚焦 | 机敏、俏皮、成熟魅力；保持真人眼睛，不加兽瞳或狐狸耳 |
| 睡凤眼 | 细长眼形，上睑自然略覆，视线仍清楚 | 松弛、慵懒、静思；不生成闭眼或失焦 |
| 细长眼 | 横向比例明显，眼睑弧度较平缓 | 克制、清醒、利落；无需套凤眼标签 |
| 上挑眼 | 外眼角略高于内眼角 | 自信、锐利；上挑程度适中 |
| 微垂眼 | 外眼角轻微下落，下睑弧线柔和 | 温和、怜惜、安静；不自动变悲伤 |
| 小鹿眼（风格俗称） | 圆润杏眼基础，目光清亮、睁眼幅度自然 | 好奇、甜美；不靠巨大瞳孔或幼态实现 |

“猫眼”可能指眼线妆，“狐狸眼”也可能指妆效；用户只改妆容时改变眼线和明暗，不擅改真实眼睛结构。各名称有重叠，选择名称之后以结构描述消除歧义，不把多个标签堆在一起。

## 脸部设计最小集

一个脸型或轮廓特征 + 一个眉眼关系 + 必要的鼻唇特点即可。不每次默认鹅蛋脸、高鼻梁、饱满唇全套；自然的面部体积、眉毛与发际线比“完美无瑕”更能支撑真人感。具体表情另放表情模块，避免同时重复微笑和眼神。

## 清晰与皮肤

- 面部和可见眼睛为对焦重点，景深覆盖鼻唇；避免只清楚一只眼、过度柔焦和皮肤过曝。
- 用柔和主光与合理环境反射保留脸部层次，不让花影、纱衣、发丝遮住眉眼。发丝受光细而自然，不形成发光描边。
- 近景可写自然毛孔、细微绒毛、唇纹；中景保留肤色变化与柔和光泽；远景只要求五官稳定、神态可辨。
- 不把“更清晰”改成锐化皮肤、粗毛孔、蜡像HDR或过度磨皮。华丽幻想背景不能把人物变成3D游戏脸。
- 默认近正面或轻微偏转；侧脸锁定时只检查可见眼睛，脸型和姿态均保持。全身锁定时压缩无关留白，不裁成半身。

## 常见修复

| 症状 | 优先调整 |
|---|---|
| 眼睛糊 | 对焦、景深、遮挡或面光中实际出错的一项 |
| 眼睛像同一模板 | 新人物时换一个眉眼结构关系；身份保持任务不换眼型 |
| 皮肤像蜡 | 还原肤色变化和柔和光比，减少磨皮与锐化词 |
| 眼型被夸张 | 保留名称但降低上挑、睁眼或狭长度，补自然成人比例 |
| 脸清楚但被背景压过 | 降低脸周装饰的对比和高光，不必删除整个复杂场景 |
