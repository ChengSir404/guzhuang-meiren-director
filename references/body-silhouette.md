# 体态、胸型与服装结构

只在用户要求身材、胸型或调用预设时细化。形状、体积、间距、领口是不同维度；只改其中一项时不要联动改其他项。术语属于衣着造型的视觉描述，不是诊断或严格医学分类。

## 选用顺序

1. 保留明确的体积与形状；只写B～C不等于已指定圆锥形，只写水滴形不等于要求丰满。
2. 必要时选一个主轮廓，加一句可见结构；不要并列相互矛盾的轮廓标签。
3. 最后按服装厚薄、支撑和姿态修正外观；宽松厚衣不必显出胸型，不制造真空贴体。
4. 杯码仅按用户要求写成“约B～C杯视觉体积”，不换算精确毫升或围度、不保证模型精确还原；杯码并非脱离下胸围的固定体积。
5. 胸型不绑定年龄、人格、职业或性感程度。避免照抄网络形状榜单中的病理化标签和优劣排名。

## 主轮廓库

| 名称 | 可直接使用的可见描述 | 防止误解 |
|---|---|---|
| 圆锥型／圆锥形 | 底盘适中，向前自然收拢，外轮廓尖挺而柔和 | 不画成硬尖、尖角衣杯或几何圆锥；不等同于管状畸形 |
| 水滴形 | 上部缓坡过渡，下部更饱满，轮廓自然下承 | 不自动扩大体积或夸张下垂 |
| 圆润形／近半球形 | 上下部饱满度较均衡，弧线圆润柔和 | 保留重力和柔软感，不做两个完全对称的硬球 |
| 钟形 | 上部较窄，下部圆润，纵向轮廓稍长 | 与水滴形有重叠，只有需要更明显纵向轮廓时选用 |
| 浅盘形／浅投射形 | 底盘相对宽缓，前突较浅，向胸廓过渡平顺 | 是本库的造型描述，不等于某一固定杯码 |
| 细长形 | 底盘较窄，整体轮廓偏长，衣料顺着纵向自然下垂 | 不与极端细腰或巨大体积硬拼 |
| 松弛自然形 | 上部较柔和，重力下轮廓自然下移，衣装提供适度支撑 | 作为可选重力特征，不默认加入年龄判断 |

这些轮廓可在真实人体中重叠；成品通常选择最影响画面的一个，其他特征用自然语言补充。

## 可选修饰维度

| 维度 | 选择范围 | 使用边界 |
|---|---|---|
| 视觉体积 | 纤秀、适中、自然丰满、较丰满；或用户指定的杯码视觉 | 不把“丰满”当作形状 |
| 间距 | 偏窄、自然、偏宽 | 间距与体积独立，不以挤压制造窄间距 |
| 走向 | 自然朝前、轻微向外 | 只在影响衣着轮廓时描述，不展开裸露细节 |
| 对称性 | 自然协调、极轻微不对称 | 不主动制造明显左右失衡 |
| 支撑 | 柔软自然、衣料适度承托 | 由服装结构决定，不写悬浮、极端上托 |

## 固定胸型／固定丰满胸型

两个名称调用同一基础预设，当前具体要求优先。只在【服装与身材】出现一次；一段话模式同样只出现一次。

> 胸部约B～C杯视觉体积，大小适中；自然圆锥型，底盘适中、尖挺但轮廓柔和，左右间距偏窄，保留真实柔软感与自然重力感，不夸张聚拢。

只说“B～C”时保留体积即可，不自动调用整段。明确改成水滴形时，用水滴形描述替换圆锥部分，其他已锁定项保留。这个预设不附带年龄、身高、腰线、领口或露肤要求。

兼容旧称：“自然丰满版”表示自然丰满的体积倾向；“较丰满版／加强版”表示较丰满，但不另绑定水滴形，也不覆盖明确的B～C。没有指定形状时可仅写体积与自然轮廓。

## 固定平口胸型

继承固定胸型基础，再追加以下服装结构；不要重复基础段：

> 穿完全不透明的抹胸上衣，领口为严格平直的水平线，衣料自然贴合并承托胸部，轮廓协调；不刻意扩大露肤，允许完整包覆，如有自然露肤，上胸肌肤露出比例至多约四分之一。

这里的比例是用户约束下的视觉上限，不是需要测量的生成参数。不自动改成低位领口、浅弧、深V或三分之一露肤。当前用户指定别的正常穿搭与露肤要求时按本轮处理。

如另要求“透明外披／不露肩”，追加：肩部与双臂由轻薄半透明丝绸长袖实际覆盖，外披叠穿在不透明内搭之外。不把“全部不透明”套到外披，也不让内搭变透明。用户明确要求完全不透明肩袖时按当前要求执行。

## 全身体态与动作

按需选高挑／适中／娇小，匀称／柔和丰满／健美，沙漏／梨形／直筒等整体轮廓；不列量体参数。坐下时腰腹与裙褶有压缩，侧卧时软组织受重力和支撑影响，站立时肩胯与承重腿对应。变化只表达自然形态，不把身体局部变成画面特写。
