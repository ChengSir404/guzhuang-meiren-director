# 体态、胸型与服装结构

新建或自由设计时，可主动选择与整体体态、服装和姿态相容的胸型；用户未指定不等于不能设计。局部修改与身份保持时不擅改已确定的形态。形状、体积、间距、领口是不同维度；只改其中一项时不要联动改其他项。术语属于衣着造型的视觉描述，不是诊断或严格医学分类。

## 选用顺序

1. 保留明确的体积与形状；只写B～C不等于已指定圆锥形，只写水滴形不等于要求丰满。未指定形状且允许整体设计时，可结合衣装自主选择一种；仅要求修改体积时不顺带改形状。
2. 必要时选一个主轮廓，加一句可见结构；不要并列相互矛盾的轮廓标签。
3. 最后按服装厚薄、支撑和姿态修正外观；宽松厚衣不必显出胸型，不制造真空贴体。
4. 杯码仅按用户要求写成“约B～C杯视觉体积”，不换算精确毫升或围度、不保证模型精确还原；杯码并非脱离下胸围的固定体积。
5. 胸型不绑定年龄、人格、职业或性感程度。避免照抄网络形状榜单中的病理化标签和优劣排名。

## 主轮廓库

| 名称 | 可直接使用的可见描述 | 防止误解 |
|---|---|---|
| 圆锥型／圆锥形 | 底盘适中，向前自然收拢，外轮廓尖挺而柔和 | 不画成硬尖、尖角衣杯或几何圆锥；不等同于管状畸形 |
| 水滴形 | 上部缓坡过渡，下部更饱满，轮廓自然下承 | 不自动扩大体积或夸张下垂 |
| 圆润形／近半球形 | 上下部饱满度较均衡，弧线圆润柔和 | 保留重力和柔软感，不做两个完全对称的硬球 |
| 钟形 | 上部较窄，下部圆润，纵向轮廓稍长 | 与水滴形有重叠，只有需要更明显纵向轮廓时选用 |
| 浅盘形／浅投射形 | 底盘相对宽缓，前突较浅，向胸廓过渡平顺 | 是本库的造型描述，不等于某一固定杯码 |
| 细长形 | 底盘较窄，整体轮廓偏长，衣料顺着纵向自然下垂 | 不与极端细腰或巨大体积硬拼 |
| 松弛自然形 | 上部较柔和，重力下轮廓自然下移，衣装提供适度支撑 | 作为可选重力特征，不默认加入年龄判断 |

这些轮廓可在真实人体中重叠；成品通常选择最影响画面的一个，其他特征用自然语言补充。

## 可选修饰维度

| 维度 | 选择范围 | 使用边界 |
|---|---|---|
| 视觉体积 | 纤秀、适中、自然丰满、较丰满；或用户指定的杯码视觉 | 不把“丰满”当作形状 |
| 间距 | 偏窄、自然、偏宽 | 间距与体积独立，不以挤压制造窄间距 |
| 走向 | 自然朝前、轻微向外 | 只在影响衣着轮廓时描述，不展开裸露细节 |
| 对称性 | 自然协调、极轻微不对称 | 不主动制造明显左右失衡 |
| 支撑 | 柔软自然、衣料适度承托 | 由服装结构决定，不写悬浮、极端上托 |

## 固定胸型／固定丰满胸型

两个名称调用同一基础预设，当前具体要求优先。只在【服装与身材】出现一次；一段话模式同样只出现一次。

> 她的上身体量适中，约为B～C杯的视觉大小。衣装下呈自然圆锥形轮廓，底部宽度适中，向前柔和收拢，略显挺拔而不尖硬。两侧间距略窄，但不刻意挤压聚拢；衣料随身体曲线垂落，保留柔软质感与自然重力感。

只说“B～C”时不自动调用整段；整体设计可另选相容形状，只改体积的请求则仅保留体积。明确改成水滴形时，用水滴形描述替换圆锥部分，其他已锁定项保留。这个预设不附带年龄、身高、腰线、领口或露肤要求。

兼容旧称：“自然丰满版”表示自然丰满的体积倾向；“较丰满版／加强版”表示较丰满，但不另绑定水滴形，也不覆盖明确的B～C。没有指定形状时可仅写体积与自然轮廓。

## 固定平口胸型

继承固定胸型基础，再追加以下服装结构；不要重复基础段：

> 她穿着完全不透明的抹胸上衣，领口平直，沿上胸形成清楚的水平线。衣料合体而不紧勒，为胸部提供适度承托。领口高度按既定遮盖要求安排，可完整包覆；若有上胸露肤，范围不超过约四分之一。

上段是适配说明。独立成品须选定一种遮盖方式，不同时保留“完整包覆／允许露肤”两个分支：未指定时采用“上衣完整包覆胸部”；已明确允许适度露肤时保留对应描述。这里的比例是预设中的视觉上限，不是需要测量的生成参数。不自动改成低位领口、浅弧、深V或三分之一露肤。当前用户指定别的正常穿搭与露肤要求时按本轮处理。

如另要求透明外披，可追加：“外搭轻薄半透明纱衣，肩部与长袖连成完整衣身，轻覆肩臂；内层抹胸保持不透明，纱衣自然垂落。”

“有薄纱覆盖”不等于“完全不透肤”。只说“不露肩”且没有进一步说明时，采用不透明肩袖，透明外披仍可叠在外层；明确允许薄纱覆肩时才使用半透明肩袖。不把内搭透明化，也不把所有外层一律改为不透明。

## 预设适配与自然表达

- 固定预设控制体量、形状或领口等指定维度，不重设年龄、脸、腰线、动作或构图。“只润色”保留全部已有设定，仅改句式与重复表达。
- 体态、衣服结构、布料受力依次写清。组合固定胸型、平口与配饰时合并重复的衣料、重力和保持说明，不将多段模板机械串联。
- 厚实宽松衣装只表达整体廓形，如“她的上身体量适中，厚实衣袍宽松垂落，衣内留有活动空间”；不为显出预设胸型而收紧或透明化衣物。
- 明确调用自然丰满版或加强版时，分别写“自然丰满”或“较为丰满”，保留已指定的形状与腰线；不把两版叠在一起，不依赖另一版本的比较措辞。
- 默认材质、体量与形状服从当前明确要求；没有原稿时将保持说明改成具体设计，不残留“沿用原有设定／按固定模板”等外部依赖。

## 全身体态与动作

按需选高挑／适中／娇小，匀称／柔和丰满／健美，沙漏／梨形／直筒等整体轮廓；不列量体参数。坐下时腰腹与裙褶有压缩，侧卧时软组织受重力和支撑影响，站立时肩胯与承重腿对应。变化只表达自然形态，不把身体局部变成画面特写。
