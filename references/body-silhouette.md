# 成年女性体态与衣着轮廓

用于用户指定身材、胸型、腰臀比例、骨架或体态，以及完整人物造型需要自动补全体型时。所有描述仅针对 **20–25 岁或用户另行指定的明确成年女性**，并通过完整、不透明、合身但不紧勒的古装呈现。

## 使用原则

1. 当前明确要求和参考图优先；不要擅自改变参考人物的体型。
2. 先定整体体型，再定胸部衣着轮廓；胸部只是整体轮廓的一部分，不单独成为视觉焦点。
3. 一次只选择一个主身材类型、一个体量等级和一个胸部轮廓，不把“极细腰、极宽胯、极丰满胸部、超长腿”同时拉满。
4. 服装结构、叠穿和时代形制优先。宽松礼服可以遮盖真实曲线，不为展示体型制造真空贴体效果。
5. 不把任何体型与纯洁、放荡、聪明、强弱等人格或道德评价绑定。
6. 用户未明确要求胸型时，成品可以只写整体体态和“上身衣着轮廓自然协调”，不必主动点名具体胸型。

## 描述顺序

按以下顺序挑选影响画面的要素，无需每项都写：

1. **身高感**：娇小、适中、修长、高挑。
2. **骨架**：纤细骨架、适中骨架、舒展骨架；避免“小骨架”与不合理巨大体量硬拼。
3. **肩颈**：窄肩、平肩、柔和溜肩、舒展直肩；颈部自然、肩颈放松。
4. **主身材类型**：梨形、沙漏形、直筒形、倒三角形、苹果/圆润形。
5. **体量与肌肉感**：纤秀、匀称、丰盈、健美；使用一个主词即可。
6. **胸部衣着轮廓**：纤秀、适中或丰满 + 水滴形、圆润形、圆盘/浅盘形。
7. **腰胯与四肢**：腰线清晰度、胯部宽缓程度、手臂和腿部线条。
8. **体态**：从容、挺拔、松弛、灵动、稳健；必须与动作和身份一致。

## 主身材类型

| 类型 | 可见轮廓 | 适合的古装人物 | 服装表现 |
|---|---|---|---|
| 梨形 / A 形 | 肩线较柔和，腰线自然，胯部与大腿更丰盈 | 贵女、花间人物、敦煌灵感美人、温柔才女 | 上身保持简洁，裙量和垂坠顺应胯部，不刻意收勒 |
| 沙漏形 / X 形 | 肩胯大致平衡，腰线较清晰，整体曲线对称 | 盛唐贵女、明艳美人、仪式性礼服人物 | 用腰带、裙腰与叠穿自然建立比例，不写极端细腰 |
| 直筒形 / H 形 | 肩腰胯差异较小，纵向线条清晰利落 | 宋韵才女、书院女先生、琴师、清冷人物 | 褙子、长衫、窄袖或纵向衣缘加强清雅线条 |
| 倒三角形 / Y 形 | 肩背较舒展有力，腰胯相对利落 | 侠女、女将、弓手、骑马人物 | 窄袖、护腕、腰带与便于活动的下装平衡肩线 |
| 苹果形 / O 形 | 躯干圆润、腰线柔和，四肢相对利落或均衡 | 成熟贵妇、富贵人物、温和端庄的生活场景 | 用顺直外层、适度裙量和垂坠面料保持端庄，不强勒腰部 |

类型不是固定模板。可使用“柔和梨形”“运动型沙漏形”“轻度倒三角形”等克制修饰，避免模型生成几何化或失真的身体。

## 胸部衣着轮廓

胸部轮廓只能写成完整衣着下的视觉形态，不描写裸露解剖细节。

| 轮廓 | 安全可见描述 | 适配建议 |
|---|---|---|
| 水滴形 | 上部过渡柔和，下部自然丰盈，侧面曲线平顺 | 最自然通用；适合梨形、沙漏形、贵女、敦煌和日常古装人物 |
| 圆润形 | 上下体量较均匀，轮廓柔和饱满，与胸廓协调 | 适合盛唐贵女、华美礼服和丰盈匀称人物；必须避免夸张上托 |
| 圆盘形 / 浅盘形 | 底盘宽缓、前突克制，横向过渡平顺，不集中隆起 | 适合直筒形、舒展骨架、宽松礼服或需要克制曲线的构图 |
| 纤秀自然形 | 体量轻盈、轮廓含蓄，与纤细骨架和清雅服装协调 | 适合宋韵、书院、琴师和清冷题材，不与“幼态”并置 |
| 丰满自然形 | 体量较丰盈但重心和过渡真实，与肩背、腰胯和整体体重匹配 | 适合丰丽贵女与敦煌灵感造型；只通过衣料剪裁呈现，不突出特写 |

“纤秀、适中、丰满”是体量；“水滴形、圆润形、圆盘/浅盘形”是轮廓。组合时各选一个，例如“适中水滴形衣着轮廓”或“丰满但克制的圆润形衣着轮廓”。

如果 ChatGPT 对直接出现“胸部”或“胸型”较敏感，将整句降级为：“上身衣着轮廓自然适中（或自然丰盈），过渡柔和，与肩背、腰胯和整体体态协调，通过完整不透明的古装剪裁自然呈现，不作为画面焦点。”不要尝试用近义敏感词绕过平台限制。

## 服装与动作适配

- **宽袖礼服、披帛、褙子**：优先表现整体衣裙轮廓和流动，不精确勾勒每一处身体曲线。
- **窄袖胡服、侠客服、骑装**：强调肩背、腰带、髋腿活动空间与衣料张力，胸部轮廓保持自然稳定。
- **坐姿、抚琴、弈棋**：腹腰和裙褶随坐姿自然压缩，避免站立时的腰胯比例原封不动。
- **骑马、舞剑、拉弓**：体态更稳健，核心收紧但不刻意挺胸；服装、发饰和珠链响应速度与惯性。
- **近景或半身**：减少腰臀和腿部描述，把重点放在肩颈、面部、手部与上衣结构。
- **全身构图**：检查头身比例、肩宽、骨盆、膝位、腿长和脚部受力是否一致。

## 禁止组合

- 未成年、幼态或少女感与丰满胸部、腰臀强调同时出现。
- 裸体、走光、透明敏感区域、深 V、乳沟、挤压、湿身、色情姿势或敏感部位特写。
- 杯码、精确围度、夸张尺寸、极端胸腰臀比例或把身体部位当商品参数罗列。
- 小骨架配超现实巨大体量、极窄肩配极宽胯、极细腰配夸张上下围等失真组合。
- 无视衣服结构的真空贴体、现代塑形内衣式集中上托或违反重力的悬浮曲线。
- 平台已经拒绝后继续替换近义词试探边界；应直接降级为整体上身衣着轮廓和服装结构描述。
