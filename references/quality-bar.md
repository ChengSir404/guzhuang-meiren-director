# 提示词质量诊断与成品标杆

当用户说“差点意思、再丰富、没有气韵、像影楼、像参数表、人物太僵、背景太假”或提供旧提示词要求改进时读取。先在心中诊断，默认直接交付修订后的成品；只有用户要求分析时才解释诊断过程。

## 症状与窄范围修复

| 症状 | 常见原因 | 优先修复 |
|---|---|---|
| 漂亮但空 | 没有当下事件和情绪潜台词 | 增加刚刚发生/即将发生的一拍，让眼神与动作透露未说出口的情绪 |
| 像服装商品页 | 名词多，人物与衣服没有因果 | 只留一个主轮廓、一个工艺焦点；写衣料如何受光、受风、受动作 |
| 像影楼写真 | 正面站姿、对称布景、装饰平均用力 | 改成决定性瞬间、非中心构图、前景遮挡和有方向的留白 |
| 人物僵硬 | 双手无任务，重心与视线不明确 | 写清双手、重心、视线对象与下一拍动作 |
| 背景像贴纸 | 只罗列亭台、花瓣、烟雾 | 增加季节/时辰/天气证据，以及风、水、光或尘土对人物的反馈 |
| 有“电影感”但画面平 | 没有真实光源、景深和色彩控制 | 指定主光、环境补光、前中后景遮挡、焦点和三色关系 |
| 每个人长得一样 | 只写完美五官、白皙皮肤、杏眼红唇 | 改用 3–4 个身份相关辨识点与一个极轻微不对称/生活痕迹 |
| 华丽但廉价 | 金银珠玉和纹样同时堆满 | 限制主发饰、面料、工艺、金属和点睛色数量，拉开哑光与亮面层次 |
| 身材像塑料模型 | 体型参数脱离服装结构、姿态与重力 | 先恢复叠穿、腰线、袖裙结构，再让衣褶随坐、走、骑、转身变化 |
| 信息很多但模型抓不住重点 | 所有细节权重相同，正负词重复 | 重排为三级视觉锚点，只保留 5–8 个会改变画面的关键细节 |

## 修订顺序

1. 保留用户不能改变的主体、时代、动作、配色或参考图身份。
2. 用一句画面核补足事件与潜台词；不要先添加更多饰品。
3. 选定第一视觉锚点，并删除争抢焦点的元素。
4. 让人物身份决定脸、衣、道具；让动作决定重心、衣褶、发饰和环境反馈。
5. 用镜头、光源、色彩和材质统一画面。
6. 最后压缩同义词和通用负面词，避免修订后比原稿更臃肿。

## 标杆一：宫宴将散的盛唐贵女

```text
【画面命题】请生成一幅真人写实、东方古典电影感人物画：暮春宫宴将散，一位 24 岁、明确成年的盛唐贵女在牡丹花径边收拢团扇；她原本正从容离席，却在听见廊下脚步时停住半步，目光越过镜头左侧，从平静中泄露一瞬迟疑。

【人物辨识度】柔和鹅蛋脸，脸颊有自然丰润感；舒展长眉与清澈含蓄的杏眼形成温柔而清醒的神情，鼻梁自然、唇峰清楚，嘴角左右略有极轻微差异。皮肤白皙通透但保留细小绒毛、唇纹和眼下淡影，拒绝网红模板脸与瓷偶磨皮。

【妆发饰品】乌发梳成轮廓饱满但不过高的唐风高髻，以一支金质花树钗为主焦点，辅以两枚小花梳和一对温润珍珠耳坠；朱红花钿小巧贴合眉眼。贵女突然停步，花树钗垂饰与耳坠仍保留轻微余摆，鬓边两缕碎发被晚风拂起。

【服装与体态】柔和沙漏形与梨形之间的丰盈匀称体态，肩颈舒展、腰胯过渡自然；穿石榴红高腰长裙、象牙白内衫与浅金披帛，服装完整、不透明、合身而不紧勒。主面料为柔亮丝绸与轻薄罗，金线只收在裙腰缘饰；丝绸随停步形成连续窄高光，披帛沿惯性向身后滑出柔和弧线，不真空贴体。

【叙事动作】右手正在合起团扇，扇骨尚未完全收拢；左手轻提裙侧以避开落花，重心由前脚移回后脚，肩部因停步微微回收。她没有直视观众，而是看向脚步来源；下一拍像是将转身确认来人。

【空间与环境】前景只用一簇轻微失焦的深红牡丹引导视线，中景承载人物和收扇动作，后景为暮色中的曲廊、稀疏宫灯和正在离席的模糊人影。晚风让花影落在衣袖上，几片花瓣越过裙摆，环境不是静止布景。

【构图与镜头】9:16 竖幅，接近全身的三分之四景，人物位于画面右侧三分线，左侧为她视线和来人方向留白；平视略低机位，约 65mm 人像透视，浅景深但保留高髻、双手、团扇和高腰裙主结构，双眼为第一对焦层。

【光色与成像】暮春暖金侧光从左后方穿过花枝，石阶与浅色墙面提供柔和正面补光，脸部明亮而不过曝；石榴红为主色、象牙白为辅色、朱红花钿与暖金珠饰作少量点睛。真人摄影质感，暗部保留织物颜色，金属只形成小面积亮点。

【必须保留 / 避免】必须保留听见脚步后的停步瞬间、未完全合拢的团扇、仍在余摆的发饰和左侧视线留白。避免未成年感、裸露或透视、深 V 与刻意塑形；避免满头珠宝、现代影楼头冠、机械回眸、正面呆站、塑料皮、手指错误、发髻或双手被裁切。
```

## 标杆二：雨后勒马的侠女

```text
【画面命题】请生成一幅真人写实、克制电影感的古装动作人像：雨后的青石山道上，一位 25 岁、明确成年的东方侠女刚勒马停在浅水边；她先于马匹察觉竹林深处的异响，动作未完成，警觉中仍有长途跋涉后的微弱疲惫。

【人物辨识度】略长椭圆脸，颧骨与下颌线清楚但不过分锋利；利落平眉、清醒凤眼、自然挺直的鼻梁和颜色克制的唇。皮肤保留雨雾湿气、眼下淡影与鬓边粘住的一缕碎发，神态沉着，不用夸张怒目或冷脸模板。

【妆发饰品】长发高束成稳固马尾式发髻，以深色皮质发带和一枚小银扣固定，不佩戴摇晃繁重的发冠；耳侧只留小型古银耳饰。马骤停后，发尾和披风仍沿前进方向保留惯性。

【服装与体态】适中舒展骨架、轻度倒三角形与运动型沙漏形之间的健美体态，肩背有力、腰胯利落、腿部稳定。穿黛青窄袖交领骑装、深灰护腕、暗红腰带和完整不透明的分层下装；粗纹绢与哑光皮革为主材质，银扣为唯一亮面点睛。衣服提供真实活动余量，不紧勒、不真空贴体。

【叙事动作】右手向后收紧缰绳，绳线有明确张力；左手按住剑鞘而未拔剑，拇指刚抵住护手。躯干随马停步略向后稳定，双腿贴合鞍具保持平衡，视线越过马耳投向竹林左前方；下一拍可能翻身下马，也可能继续前行，但当前只呈现勒马与判断的一瞬。

【空间与环境】前景是一小片被马蹄踏开的浅水和飞溅泥点，中景为人物、马、缰绳与剑的完整关系，后景竹林被雨雾分成深浅层次。湿青石反射冷天光，马的前蹄刚落水，鼻息在凉空气里形成极淡白雾；竹叶滴水，披风下缘带有真实湿重感。

【构图与镜头】16:9 横幅，中远景，人物与马位于右侧，左前方为异响来源和运动留白；略低机位、约 50mm 自然透视，快门感冻结主要动作但允许发尾和水滴轻微运动模糊。对焦先落人物双眼，再落握缰手与马头，马腿、鞍具和人物腿位完整可信。

【光色与成像】阴雨天冷灰漫射光为主，湿路面提供微弱上方反射补光，让脸部和眼睛清楚可读；黛青为主色、深灰为辅色、暗红腰带为唯一暖色锚点。皮革吸光、湿石反光、粗纹绢在褶皱转折处出现细弱亮边，整体低饱和但不死黑。

【必须保留 / 避免】必须保留勒紧的缰绳、按剑未拔、马蹄入水与左前方警觉视线。避免静态摆拍、双手失去任务、马具缺失、人物悬浮、马腿畸形、披风逆物理飘动；避免现代紧身服、裸露或透视、敏感部位焦点、廉价仙侠光效、过度锐化和暗脸。
```

## 标杆判断

标杆不是要求复制固定措辞，而是检验四件事：用户能一眼看出发生了什么；人物为什么这样穿和这样动；环境与光为什么呈现成这样；删掉任何一个视觉锚点都会明显改变画面。
