# 质量诊断

有生成图就先看整图与问题区域；只有文字反馈时把原因当假设，不声称已观察到问题。所有修复服从原稿保持项；用户明确要求全面重做时才同时重设计多项。

| 症状 | 最小修复方向 |
|---|---|
| 脸或皮肤糊 | 检查景深、对焦、面光、遮挡；全身锁定时不裁近，降低无关留白与背景抢眼程度 |
| 皮肤假、像3D | 去掉瓷白无瑕、过度柔焦和锐化堆词，恢复自然肤色变化、柔和反射和皮肤微纹理 |
| 眼型总一样 | 新人物时按气质与场景更换眼型或眉眼关系；身份参考锁定时只调整妆容与清晰度 |
| 表情僵 | 将形容词换成一个目光变化与一个嘴角变化，减少挑眉、咬唇、歪头同时发生 |
| 坐姿悬空、滑落 | 明确骨盆落在足够宽的承托面内，脚或手的辅助支撑与椅子方向一致 |
| 多腿、手指纠缠 | 减少交叉遮挡，明确一条腿或一只手的关键位置；只修对应动作，不重造场景 |
| 脚背小腿成直线 | 让踝部自然弯折，脚尖按姿势放松；不要给站立高跟鞋、跪姿与侧卧硬套同一角度 |
| 脚尖勾鞋失败 | 明确上方脚前掌入鞋、脚跟离开后帮、鞋跟朝地；不让鞋悬空无接触 |
| 薄袖消失 | 写清薄袖覆盖肩部并连接袖身，叠在不透明内搭外；身后飘带不能替代袖子 |
| 胸型或领口漂移 | 分开体积、轮廓、领口直线与内外层；去除同段冲突形状，不更换脸或动作 |
| 像棚拍、背景贴纸 | 检查接触阴影与空间光照，添加一处环境联系；正面和静态本身不是错误 |
| 画面华丽但杂乱 | 降低脸周反光、花枝与首饰竞争，删一处次要装饰，不必推翻整个场景 |
| 每张都托花、抬腿、回眸 | 先换姿态家族或手部任务，再匹配神态；只改花名和颜色无效 |
| 提示词越改越长 | 保留不可丢项，合并同义要求，去掉看不见的微细节、重复负面词和多余解释 |

默认只交付替换段；用户要全文时整合。没有实际出图测试时，不宣称已解决生成模型所有畸形或通过平台审核。
