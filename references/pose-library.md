# 姿态与动作库

目录：选择原则 → 坐姿 → 站姿 → 跪卧与动态 → 手部互动 → 脚与鞋 → 组合检查。

本库是面向单张人像的原创动作拆解，不是医学或舞蹈标准分类。按场景选择一个姿态家族、一个主要动作，必要时补承重点。无需把每个关节都写入成品。

## 选择原则

- 用户已指定的坐、站、卧及朝向优先；“更好看”不等于允许全换。
- 自然好看来自重心、肩胯和手脚配合，不是固定抬腿、挺胸或拧腰。
- 先确定支撑面，再定腿部，最后安排手与视线。支撑手不能同时拿另一件物品。
- 只明确镜头可见且容易失败的关系；自然垂手不必强加任务，闭眼或低头只在用户允许时选。
- 避免与近期可见方案重复同一姿态家族；不能只改“左手”为“右手”就宣称新动作。

## 坐姿：13种基础结构

| 姿态 | 支撑与腿部 | 手部与适配 |
|---|---|---|
| 正坐椅面 | 骨盆落在座面，双脚自然着地，肩背舒展 | 手放膝上、扶手或桌面；适合端庄、知性 |
| 前半座轻斜坐 | 坐骨仍在座面内，骨盆轻斜，背不贴满椅背 | 一手扶独立扶手，另一手放膝上；高背椅不能变沙发 |
| 侧坐转上身 | 骨盆朝座面侧方，双腿向同侧安放，上身适度转向镜头 | 手扶座缘保持平衡；不极端扭转腰部 |
| 双膝并拢斜放 | 椅面承重，膝部自然靠近，小腿斜向一侧 | 手轻叠膝上；不把两腿融合 |
| 交踝坐 | 双膝自然靠近，两脚在踝部轻交叉 | 放松手臂；与膝上交叠二郎腿区分 |
| 二郎腿 | 一侧大腿搭于另一侧膝上，下方脚稳妥支撑 | 手落扶手或膝侧；不再额外叠第三条腿 |
| 盘腿坐 | 臀部落在宽平坐面，双腿交叉收在身前 | 手落膝或身侧；窄椅面不硬塞盘腿 |
| 侧叠腿席坐 | 坐于席面，双膝弯曲，小腿收向身体同一侧 | 一手可撑席面，另一手放腿上；裙摆不掩盖错误结构 |
| 长坐微屈膝 | 坐骨落地，双腿向前但膝微松，不锁直 | 身后手掌或靠垫提供自然支撑 |
| 屈膝环抱坐 | 坐面足够宽，双脚收于身前，膝自然弯曲 | 前臂轻搭膝上；脸不埋进膝间 |
| 台面坐、双腿下垂 | 骨盆完整落在足够宽的稳固台面内，腿垂在边缘外 | 一手撑在身体侧后方；不坐在不可承重水槽内或滑出台边 |
| 靠背放松坐 | 背部与椅背实际接触，骨盆与座面接触 | 手落扶手，肩颈自然；不靠夸张塌腰表现慵懒 |
| 半倚坐 | 坐骨承重，一侧前臂或软靠垫辅助，躯干轻斜 | 腿顺着坐面安放；明确坐而非整人悬空 |

盘腿、交踝、二郎腿是不同腿部关系，成品只能选定一种。用户说“整个人坐台面”若指腿也收上台面，选择宽台盘腿或屈膝坐，不写双腿同时垂地。

## 站姿：10种基础结构

| 姿态 | 重心与脚步 | 合适的动作 |
|---|---|---|
| 自然正立 | 双脚自然分开承重，膝放松，肩线舒展 | 垂手、持物、正面凝视；静态也成立 |
| 单侧承重 | 重心偏一条腿，另一脚仍接触地面 | 一手轻搭腰侧衣料；不自动抬起空闲腿 |
| 前后错步 | 前后脚错开但都可落地，骨盆保持稳定 | 停步交谈、迎风站定 |
| 小幅侧步站定 | 一脚向侧方落地，身体重心回到支撑区域 | 扶门、让路、绕开植物 |
| 行走停顿 | 前脚已落地，后脚自然过渡，肩线有惯性 | 眼神先回应镜头，身体慢半拍；不用每次提裙 |
| 倚柱／倚墙 | 肩背或前臂轻接触支撑物，双脚保持稳定 | 放松另一只手；不能穿进墙体 |
| 扶栏站立 | 双脚承重，手或前臂落在实际栏杆高度 | 交叠双手、轻搭栏边；身体不悬到栏外 |
| 轻俯身站立 | 从髋部小幅前倾，双脚稳定，颈部不过度折弯 | 观察低处、整理物件；正脸需求下抬眼角度自然 |
| 半转身站定 | 脚步与髋部配合转动，躯干不超过合理扭转 | 转动衣袖、回应侧方；不是默认回眸 |
| 登阶落脚瞬间 | 一脚完整落在台阶上，后脚仍在下一级 | 手扶栏或自然垂落；这是实际登阶而非无缘由抬腿 |

## 跪、卧与动态：8种结构

| 姿态 | 必要结构 | 使用边界 |
|---|---|---|
| 跪坐／正座 | 膝与小腿落在垫面，臀部由脚跟区域承托 | 服装与垫面适合；不硬套坐椅时的踝角 |
| 侧跪坐 | 双膝弯曲，小腿偏向一侧，臀部落在腿侧垫面 | 区别于臀部坐脚跟的正座 |
| 单膝跪姿 | 一膝着地，另一脚完整着地，骨盆稳定 | 适合仪式或战斗停顿，不让双腿方向互相拧转 |
| W坐 | 双膝弯曲在前，小腿位于身体两侧，臀部落地 | 仅按用户明确要求选用，不作为通用默认，不夸张髋膝角度 |
| 侧卧 | 肩侧、髋侧与承托面接触，头有枕或前臂支撑 | 双腿自然轻屈，避免凭空扭腰 |
| 斜倚卧 | 上背由靠垫支撑，骨盆与腿落在足够长的座榻 | 服装覆盖随姿态合理，不写腰臀悬空 |
| 缓步／转步 | 截取一只脚落地、另一脚过渡的明确时刻 | 衣摆与发尾有有限惯性，脸不运动模糊 |
| 旋身扬袖 | 支撑脚稳定，另一脚完成小幅转步，上身与袖子形成弧线 | 只冻结一个姿态；不同时跳跃、回眸、换腿 |

## 手部与物体互动

从下列任务取一个；另一手自然放置或承担必要支撑，避免双手各做一场戏。

| 任务 | 可执行关系 |
|---|---|
| 扶门／推窗 | 掌指接触把手或边缘，肘部与开合方向一致 |
| 托杯／双手捧盏 | 一手托底、一手扶侧，手指不穿杯；不用所有手指抢抓细柄 |
| 执笔／写生 | 主手握笔，另一手稳定纸张或自然放置；笔尖与纸面关系明确 |
| 落棋子 | 拇指与食指捏一枚棋子的边缘，其余手指自然收拢；不同时悬空多枚 |
| 理袖口 | 一手轻整另一侧袖缘，被整理手臂放松，避免两手纠缠 |
| 挽住外披 | 指尖握住真实衣缘，布料受力方向对应手的位置 |
| 碰触植物 | 手接触可触及的花枝位置，花茎有连续结构；不是默认动作 |
| 扶发饰／耳坠 | 指尖在耳侧，面部无遮挡；单张图只描述瞬间，不写长时间停留 |
| 持剑／持伞 | 握持真实柄部；未撑开的伞保持收拢，剑刃与身体分离 |
| 结印 | 双手在胸前留出空间，选简单清楚的相对关系；不堆复杂交叉手指 |
| 拉弓 | 一手握弓，一手拉弦，弦、箭与双手位置一致 | 
| 松弛垂手 | 手指自然轻曲，手腕不过折；无需靠道具证明动作成立 |

## 脚踝、鞋与脚链

- 脚背和小腿不要无缘由拉成直线，脚踝按落地、下垂、侧放等实际姿势自然弯折。用户指定90°～120°时作为该画面的视觉约束；不当成所有鞋型、跪姿的统一人体标准。
- 双脚入镜时两脚都检查；要求完整脚部时避免脚趾、鞋尖或鞋跟被裁掉。长裙遮住脚时不强行增加看不见的细节。
- 高跟鞋站姿应符合鞋底与地面接触；不把赤足踝部角度照搬到高跟鞋。
- “脚尖勾鞋／半脱高跟鞋”仅按用户要求：二郎腿上方脚只以前脚掌留在鞋头，脚跟离开鞋后帮，鞋跟朝地面，鞋尖与脚尖形成自然夹角；下方脚稳定支撑。明确要求30°～60°时再加数值，不自动写进所有坐姿。
- 单侧脚链只佩在一只脚踝，不额外复制到另一只；不因加脚链改鞋色、裙长或姿态。

## 最后检查

座面宽度够不够？骨盆在哪里承重？脚与地面或坐面关系是否唯一？手有没有同时承担两个冲突任务？脸是否可见？服装是否允许这个动作？只把最影响结果的答案写入成品。
